<Definition term="直角三角形の辺">
直角三角形で、直角の向かい側にある辺を**斜辺**という。斜辺は3つの辺の中で最も長い。
</Definition>

<Figure caption="直角三角形。斜辺は直角の向かい側にある、いちばん長い辺です。">
<RightTriangle deg={30} />
</Figure>

<Theorem name="三平方の定理">
直角三角形の直角をはさむ2辺の長さを $a$、$b$、斜辺の長さを $c$ とすると

$$
a^2 + b^2 = c^2
$$

が成り立つ。逆に、三角形の3辺 $a$、$b$、$c$（$c$ が最も長い）について $a^2 + b^2 = c^2$ が成り立つならば、その三角形は $c$ の向かいの角が直角である。
</Theorem>

<Why>
三平方の定理で $c$ に斜辺を選ぶのは、この定理が「2辺の2乗の和は、直角の向かい側の辺の2乗に等しい」という形だからです。斜辺は直角三角形を見ればひとつに決まるので、図で直角を確認してから、その向かい側の辺を $c$ とおけば迷いません。
</Why>

<KeyPoint>
よく出る辺の比：$3:4:5$、$5:12:13$、直角二等辺三角形は $1:1:\sqrt{2}$、$30^\circ$・$60^\circ$・$90^\circ$ は $1:\sqrt{3}:2$。覚えておくと計算を省けます。
</KeyPoint>

## 例題

<WorkedExample title="例題: 2点間の距離">
座標平面上の2点 $A(1, 1)$、$B(4, 5)$ の距離 $AB$ を求めなさい。

<Steps>
<Step reason="斜めの距離は直接読めないので、x と y の差から直角三角形を作ります。">x の差は $4 - 1 = 3$、y の差は $5 - 1 = 4$。</Step>
<Step reason="x 方向と y 方向は直角に交わるので、この2辺を直角をはさむ辺とする直角三角形になります。">求める距離は、直角をはさむ2辺が $3$ と $4$ の直角三角形の斜辺になる。</Step>
<Step reason="三平方の定理で斜辺の長さを求めます。">$AB^2 = 3^2 + 4^2 = 9 + 16 = 25$。</Step>
<Step reason="長さは正なので、2乗を外します。">よって $AB = \sqrt{25} = 5$。</Step>
</Steps>

<Answer>
$AB = 5$。
</Answer>
</WorkedExample>

<Misconception>
<Wrong>
三平方の定理 $a^2 + b^2 = c^2$ で、$c$ は図で右側にある辺、または最初に目についた辺である。
</Wrong>
<WhyWrong>
$c$ に入れるのは斜辺、すなわち直角の向かい側にある最も長い辺だけです。斜辺でない辺を $c$ に代入すると、たとえば $5$、$12$、$13$ の直角三角形で $5^2 + 13^2$ を計算してしまい、正しい長さになりません。位置ではなく、直角の向かい側かどうかで決まります。
</WhyWrong>
<Right>
まず直角の記号を探し、その向かい側の辺に斜辺の印を付けます。その辺を $c$、残りを $a$、$b$ として $a^2 + b^2 = c^2$ に代入します。
</Right>
</Misconception>

<CheckUnderstanding>
1. 直角をはさむ2辺が $9$ と $12$ の直角三角形の斜辺を求めなさい。

2. 3辺が $5$、$12$、$13$ の三角形は直角三角形か。また、$4$、$5$、$6$ の三角形はどうか。
<Reveal label="答え">
1. $9^2 + 12^2 = 81 + 144 = 225$ なので斜辺は $\sqrt{225} = 15$。$3:4:5$ を $3$ 倍した比 $9:12:15$ としても同じです。

2. $5^2 + 12^2 = 25 + 144 = 169 = 13^2$ なので直角三角形。$4^2 + 5^2 = 16 + 25 = 41$、$6^2 = 36$ で等しくないので直角三角形ではない。
</Reveal>
</CheckUnderstanding>

<Practice title="特別な角の三角形">
$30^\circ$・$60^\circ$・$90^\circ$ の直角三角形で、最も短い辺の長さが $5$ であるとき、斜辺と残りの辺の長さを求めなさい。
<Reveal label="解答">
辺の比は短い辺 : 長い辺 : 斜辺 $= 1 : \sqrt{3} : 2$。最も短い辺が $5$ なので、残りの辺は $5\sqrt{3}$、斜辺は $10$。
</Reveal>
</Practice>

## 高校・入試での用途
数学I「図形と計量」の余弦定理・正弦定理は、三平方の定理を一般の角に広げたものです。数学II「図形と方程式」の2点間の距離の公式、数学C「ベクトル」の大きさ、空間図形の対角線まで、直角三角形さえ見つければ三平方で片づきます。$3:4:5$ などの比を覚えておくと、入試の計算時間を確実に短縮できます。
