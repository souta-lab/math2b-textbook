## どの定理を選ぶか

図形の条件を見て、最初に手を伸ばす定理を決めます。次の表を、問題を見たときの判断の出発点にしてください。

| 図で見つけたもの | 最初に使う定理 | 何が分かるか |
| --- | --- | --- |
| 平行線と横断線 | 同位角・錯角 | 角を離れた場所へ移せる |
| 等しい辺・角の組 | 合同 | 辺や角を丸ごと移せる |
| 平行線、または2組の等しい角 | 相似 | 辺の比を立てられる |
| 直角と2辺 | 三平方の定理 | 残りの辺の長さ |
| 円と弦、弧 | 円周角の定理 | 中心角の半分、等しい角 |

<Contrast title="合同と相似の使い分け">
**合同**は形も大きさも同じ。対応する辺をそのまま移せるので、長さや角の「等しさ」を示すのに使います。**相似**は形だけが同じ。辺の比が分かるので、長さの「比」や面積比を求めるのに使います。相似比が $1$ の相似が、ちょうど合同にあたります。
</Contrast>

<WorkedExample title="例題: 相似と三平方をつなぐ">
直角三角形 ABC で $\angle A = 90^\circ$ とし、頂点 A から斜辺 BC に垂線 AH を下ろします。$BH = 4$、$CH = 9$ のとき、$AH$ と $AB$ を求めなさい。

<Steps>
<Step reason="垂線によって、直角を共有する2つの小さな直角三角形ができます。角を対応させると相似が言えます。">$\angle AHB = \angle CHA = 90^\circ$ で、$\angle ABH = \angle CAH$ より $\triangle ABH \sim \triangle CAH$。</Step>
<Step reason="相似の対応順から、AH が2つの三角形で対応する辺になります。">対応する辺の比から $AH : BH = CH : AH$、すなわち $AH^2 = BH \cdot CH$。</Step>
<Step reason="ここで三平方や辺の長さを使わずに、相似だけで AH が出ます。">$AH^2 = 4 \times 9 = 36$ なので $AH = 6$。</Step>
<Step reason="AB も相似から出します。△ABH と △CBA は角 B が共通で、別の角が直角です。">$\triangle ABH \sim \triangle CBA$ より $AB : CB = BH : AB$、すなわち $AB^2 = BH \cdot BC$。</Step>
<Step reason="BC は BH と CH の和です。">$BC = 4 + 9 = 13$ だから $AB^2 = 4 \times 13 = 52$、よって $AB = 2\sqrt{13}$。</Step>
</Steps>

<Answer>
$AH = 6$、$AB = 2\sqrt{13}$。
</Answer>
</WorkedExample>

<Why>
相似で長さの比を作ってから、必要なところだけ三平方で長さに変える、という順序が有効です。相似は角の情報だけで辺の比を与え、三平方は直角の情報だけで具体的な長さを与えます。手元にある情報がどちらかを1行で見極めてから式を立てると、迷う時間が減ります。
</Why>

<Misconception>
<Wrong>
相似比が $2:3$ の2つの図形では、面積比も $2:3$ である。
</Wrong>
<WhyWrong>
相似比は長さの比です。面積は縦と横の2方向にそれぞれ拡大されるので、相似比 $k$ に対して面積比は $k^2$ になります。$2:3$ なら面積比は $2^2:3^2 = 4:9$ です。体積なら3方向に効くので $k^3 = 8:27$ になります。
</WhyWrong>
<Right>
長さの比は相似比のまま、面積比はその2乗、体積比はその3乗を使います。相似比を求めたら、いま欲しいのが長さ・面積・体積のどれかを確認してから累乗します。
</Right>
</Misconception>

<CheckUnderstanding>
次の問いを、まず自力で解いてから開いてください。

1. $\ell \parallel m$ で、折れた線の角が $x$、その上が $40^\circ$、下が $35^\circ$ のとき、$x$ を求めよ。

2. 3辺が $9$、$12$、$15$ の三角形は直角三角形か。

3. 円 O で、弧 AB の中心角が $120^\circ$ のとき、円周角を求めよ。

4. 相似比 $5:2$ の2つの相似な図形の面積比を求めよ。
<Reveal label="答え">
1. 同位角・錯角で折れ角を分けると $x = 40^\circ + 35^\circ = 75^\circ$。

2. $9^2 + 12^2 = 81 + 144 = 225 = 15^2$ なので、$15$ を斜辺とする直角三角形である。

3. 円周角は中心角の半分なので $120^\circ \div 2 = 60^\circ$。

4. 面積比は相似比の2乗なので $5^2:2^2 = 25:4$。
</Reveal>
</CheckUnderstanding>

<Practice title="総合問題">
円 O の直径を AB とし、$AB = 10$ とします。円周上に点 C をとり、$AC = 6$ であるとき、$BC$ の長さと三角形 ABC の面積を求めなさい。
<Reveal label="解答">
AB は直径なので、半円の弧に対する円周角より $\angle ACB = 90^\circ$。よって三角形 ABC は斜辺 $AB = 10$ の直角三角形です。三平方の定理から $BC^2 = 10^2 - 6^2 = 100 - 36 = 64$、$BC = 8$。面積は直角をはさむ2辺を使って $\dfrac{1}{2} \times 6 \times 8 = 24$。
</Reveal>
</Practice>

## 高校・入試での用途
相似・三平方・円周角を組み合わせた図形総合問題は、数学I「図形と計量」と数学A「図形の性質」、数学C「ベクトル」の入口です。どの定理を使うかを瞬時に判断する力は、入試の図形問題で時間を大きく左右します。図を見たらまず平行線・直角・等しい角・円の弧を探し、対応する行を思い出してから手を動かしてください。
