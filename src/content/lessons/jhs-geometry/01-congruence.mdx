さきほど、2直線が平行なときは角が移せることを学びました。今回は、等しい辺や角を手がかりに「三角形まるごとが同じ」と言い切る条件を整理します。

<Definition term="合同">
2つの図形を、ずらしたり回したり裏返したりしてぴったり重ね合わせられるとき、それらは**合同**であるという。合同な三角形では、対応する辺と角がそれぞれ等しい。$\triangle ABC \equiv \triangle DEF$ と書いたとき、頂点は $A \leftrightarrow D$、$B \leftrightarrow E$、$C \leftrightarrow F$ の順に対応している。
</Definition>

<Theorem name="三角形の合同条件">
2つの三角形は、次のいずれかが成り立つとき合同である。

- 3組の辺がそれぞれ等しい
- 2組の辺と、その間の角がそれぞれ等しい
- 1組の辺と、その両端の角がそれぞれ等しい
</Theorem>

<Why>
合同条件を使い分けるのは、いま分かっている等しい量（辺か角か、そしてそれらが隣り合っているか）に合わせて、測る手間を最小にするためです。3辺だけ、2辺と間の角だけ、1辺と両端の角だけのどれかがそろえば、残りの辺や角を測らなくても形と大きさが決まります。
</Why>

## 合同は「証明の道具」

合同はそれ自体が目的ではなく、対応する辺や角が等しいことを示すための道具です。合同を示せば、「同じ図形の一部分だから」と言って長さや角を移せます。

## 例題

<WorkedExample title="例題: 合同から性質を導く">
三角形 ABC は $AB = AC$ の二等辺三角形で、頂角 A の二等分線 AD が辺 BC と交わるとします。このとき $\triangle ABD \equiv \triangle ACD$ を示し、$BD = DC$ と $\angle ADB = 90^\circ$ を導きなさい。

<Steps>
<Step reason="二等辺三角形の定義から、対応する2辺が等しいと言えます。">$AB = AC$（仮定）。</Step>
<Step reason="AD が頂角 A の二等分線だからです。">$\angle BAD = \angle CAD$。</Step>
<Step reason="辺 AD は2つの三角形に共通なので、同じ長さです。">$AD$ は共通。</Step>
<Step reason="2組の辺とその間の角がそれぞれ等しいので、合同条件が使えます。">よって $\triangle ABD \equiv \triangle ACD$（2組の辺とその間の角）。</Step>
<Step reason="合同な図形では対応する辺が等しいからです。">対応する辺だから $BD = DC$。</Step>
<Step reason="B・D・C は一直線上にあり、等しい角の和は $180^\circ$ になります。">$\angle ADB = \angle ADC$ で、その和は $180^\circ$。よって各 $90^\circ$。</Step>
</Steps>

<Answer>
$\triangle ABD \equiv \triangle ACD$。したがって $BD = DC$、$\angle ADB = 90^\circ$。頂角の二等分線は底辺を垂直に二等分します。
</Answer>
</WorkedExample>

<Misconception>
<Wrong>
2組の辺と1組の角がそれぞれ等しければ、いつでも合同である。
</Wrong>
<WhyWrong>
等しい角が2辺の「間」にない場合、同じ2辺と角をもつ三角形が2通り作れてしまい、合同とは限りません。たとえば辺 4、辺 5、角 $30^\circ$ が与えられても、角の位置によって形が変わります。また、合同条件は辺や角の「数」だけではなく、対応の位置関係まで指定しています。
</WhyWrong>
<Right>
使えるのは「3組の辺」「2組の辺とその間の角」「1組の辺とその両端の角」。等しい角が2辺の間にくるか、辺の両端にくるかを図で確かめてから条件を選びます。
</Right>
</Misconception>

<CheckUnderstanding>
1. 三角形 ABC と三角形 DEF について、$AB = DE$、$BC = EF$、$\angle B = \angle E$ が分かっている。どの合同条件が使えるか。

2. $\triangle ABC \equiv \triangle DEF$ のとき、$BC = 7$、$CA = 5$ ならば、$EF$ と $FD$ はそれぞれいくらか。
<Reveal label="答え">
1. 2組の辺とその間の角（$AB$ と $BC$ の間の角が $\angle B$、$DE$ と $EF$ の間の角が $\angle E$）が等しいので、この条件で合同が言えます。

2. 対応順から $B \leftrightarrow E$、$C \leftrightarrow F$ なので $EF = BC = 7$。同様に $C \leftrightarrow F$、$A \leftrightarrow D$ より $FD = CA = 5$。
</Reveal>
</CheckUnderstanding>

## 高校・入試での用途
数学A「図形の性質」の証明は、まず合同によって辺や角の相等を示すところから始まります。二等辺三角形の性質や作図の根拠も合同条件にあります。入試では「対応順を正しく書く」ことがそのまま論証の正確さになります。

<Practice title="確認（合同と角）">
（1）$\triangle ABC$ と $\triangle DEF$ で、$AB=DE$、$BC=EF$、$\angle B=\angle E$ である。使える合同条件を答え、$\angle A=\angle D$ と言えるか。

（2）2直線 $AB$ と $CD$ が点 $O$ で交わり、$AO=BO$、$CO=DO$ である。対頂角の関係を使って $\triangle AOC \equiv \triangle BOD$ を示せ。

<Reveal label="解答">
（1）$AB$ と $BC$ の間の角が $\angle B$、$DE$ と $EF$ の間の角が $\angle E$ なので、「2組の辺とその間の角」が使える。合同なので対応する角が等しく、$\angle A=\angle D$ と言える。

（2）対頂角は等しいので $\angle AOC=\angle BOD$。$AO=BO$、$CO=DO$ で、その間の角が等しいので、「2組の辺とその間の角」より $\triangle AOC \equiv \triangle BOD$。
</Reveal>
</Practice>
