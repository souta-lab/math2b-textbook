## 距離が一定であること

中心 $C(a, b)$ と、円周上の点 $P(x, y)$ を考えます。$P$ が円周上にある条件は、$CP$ の距離が半径 $r$ に等しいことです。前のレッスンの距離の式をそのまま使うと、次の関係が得られます。

<Figure caption="中心 (1, 2)、半径 3 の円。緑の線分が半径を表します。">
<Circle cx={1} cy={2} r={3} showRadius xMin={-3} xMax={5} yMin={-2} yMax={6} label="中心(1,2)半径3の円" />
</Figure>

<Why>
円の式を作るとき、2乗したままにしておくのは、平方根を残さないためです。距離の式は $\sqrt{(x - a)^2 + (y - b)^2} = r$ ですが、両辺を2乗すれば根号が消え、$r^2$ という扱いやすい形になります。円周上の点と中心の距離が一定、という素朴な条件がそのまま方程式になります。
</Why>

<Definition term="円の方程式">
中心 $C(a, b)$、半径 $r$ の円の方程式は

$$
(x - a)^2 + (y - b)^2 = r^2
$$

である。これを展開して整理した

$$
x^2 + y^2 + Dx + Ey + F = 0
$$

の形を、円の方程式の**一般形**という。
</Definition>

一般形を見ただけでは中心と半径が分かりません。そこで、$x$ と $y$ のそれぞれについて平方完成し、上の標準形に戻します。一般形では $x^2$ と $y^2$ の係数が等しく、$xy$ の項がないことに注意してください。この形でなければ円を表しません。

<WorkedExample title="例題: 一般形から中心と半径を読む">
円 $x^2 + y^2 - 4x + 6y - 3 = 0$ の中心と半径を求めよ。

<Steps>
<Step reason="中心と半径を読むには、(x - a)² + (y - b)² = r² の形に戻したいからです。">$x$ の項をまとめて平方完成する。$x^2 - 4x = (x - 2)^2 - 4$。</Step>
<Step reason="y についても同じ操作を行います。">$y^2 + 6y = (y + 3)^2 - 9$。</Step>
<Step reason="定数を右辺に集めると、半径の2乗が現れます。">$(x - 2)^2 - 4 + (y + 3)^2 - 9 - 3 = 0$ より $(x - 2)^2 + (y + 3)^2 = 16$。</Step>
<Step reason="標準形の形から、中心と半径を直接読み取れます。">中心は $(2, -3)$、半径は $\sqrt{16} = 4$。</Step>
</Steps>

<Answer>
中心 $(2, -3)$、半径 $4$。
</Answer>
</WorkedExample>

## 3点を通る円

円の方程式の一般形 $x^2 + y^2 + lx + my + n = 0$ には、定数 $l$、$m$、$n$ の3つが入っています。円を1つ決めるには中心の座標2つと半径1つ、合わせて3つの数が必要でした。未知数が3つあれば、通る3点を代入して得られる3本の条件式から、円は1つに定まります。

<WorkedExample title="例題: 3点を通る円">
3点 $A(7, 1)$、$B(2, 6)$、$C(-3, 1)$ を通る円の方程式を求めよ。

<Steps>
<Step reason="通る3点から条件が3本得られるので、未知数がちょうど3つの一般形でおくのが自然です。">求める円の方程式を $x^2 + y^2 + lx + my + n = 0$ とおく。</Step>
<Step reason="円周上の点は方程式を満たすので、3点の座標を代入すると l, m, n の連立方程式になります。">3点をそれぞれ代入する。
$A$: $50 + 7l + m + n = 0$
$B$: $40 + 2l + 6m + n = 0$
$C$: $10 - 3l + m + n = 0$</Step>
<Step reason="A と C の式を辺々引くと m と n が消え、l だけの式になります。">$A - C$ より $40 + 10l = 0$。よって $l = -4$。</Step>
<Step reason="B と C を引けば n も消えるので、同じ要領で m が求まります。">$B - C$ より $30 + 5l + 5m = 0$。$l = -4$ を代入して $30 - 20 + 5m = 0$、すなわち $m = -2$。</Step>
<Step reason="l と m が分かったので、残り1つの式に代入して n を求めます。">$C$ より $10 + 12 - 2 + n = 0$ なので $n = -20$。</Step>
<Step reason="一般形のままでも円を表しますが、平方完成すると中心と半径が読めて検算にもなります。">$x^2 + y^2 - 4x - 2y - 20 = 0$ を平方完成すると $(x - 2)^2 + (y - 1)^2 = 25$。</Step>
</Steps>

<Answer>
$(x - 2)^2 + (y - 1)^2 = 25$（一般形では $x^2 + y^2 - 4x - 2y - 20 = 0$）。中心 $(2, 1)$、半径 $5$。
</Answer>
</WorkedExample>

<Why>
標準形 $(x - a)^2 + (y - b)^2 = r^2$ でも未知数は $a$、$b$、$r$ の3つですが、点の座標を代入すると2乗を含む式になり、連立方程式が解きにくくなります。一般形なら代入しても $x^2 + y^2$ の部分が数値になるだけなので、3つの条件がすべて $l$、$m$、$n$ についての1次式になり、加減法で順に消去できます。これが「3点が与えられたら一般形でおく」理由です。
</Why>

<Misconception>
<Wrong>
円 $x^2 + y^2 - 4x + 6y - 3 = 0$ の中心は $(-4, 6)$ である。
</Wrong>
<WhyWrong>
一般形の係数 $D$、$E$ はそのまま中心にはなりません。理由は平方完成にあります。$(x - 2)^2$ を展開すると $-4x$ が現れるので、$-4x$ からは中心の x 座標 $2$ が逆算されます。中心は $\left(-\dfrac{D}{2}, -\dfrac{E}{2}\right)$ です。
</WhyWrong>
<Right>
一般形は必ず平方完成して標準形に直します。$x^2 + y^2 + Dx + Ey + F = 0$ なら、中心は $\left(-\dfrac{D}{2}, -\dfrac{E}{2}\right)$、半径は $\sqrt{\dfrac{D^2 + E^2}{4} - F}$ です。
</Right>
</Misconception>

<CheckUnderstanding>
(1) 中心 $(-2, 1)$、半径 $4$ の円の方程式を求めよ。

(2) 円 $x^2 + y^2 + 6x - 2y - 6 = 0$ の中心と半径を求めよ。

(3) $x^2 + y^2 + 2x + 2y + 5 = 0$ は円を表すか。

<Reveal label="答え">
(1) $(x + 2)^2 + (y - 1)^2 = 16$。

(2) 平方完成すると $(x + 3)^2 + (y - 1)^2 = 16$。中心 $(-3, 1)$、半径 $4$。

(3) 平方完成すると $(x + 1)^2 + (y + 1)^2 = -3$。右辺が負なので、実数の点は存在せず円を表さない。
</Reveal>
</CheckUnderstanding>

<Practice title="中心と半径をそろえる">
円 $x^2 + y^2 - 8x + 2y + 8 = 0$ の中心と半径を求めよ。
<Reveal label="解答">
$x^2 - 8x = (x - 4)^2 - 16$、$y^2 + 2y = (y + 1)^2 - 1$。よって $(x - 4)^2 + (y + 1)^2 = 9$。中心 $(4, -1)$、半径 $3$。
</Reveal>
</Practice>
