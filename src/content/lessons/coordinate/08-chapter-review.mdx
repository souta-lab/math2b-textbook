## 道具の見分け方 — 章末の判断表

問題文を読んだら、まず「求めるものは点の座標か、点の集合（図形や範囲）か」を確かめます。条件と道具の対応を、次の表で総点検してください。

| 問題に出てくる形 | 使う道具 | 決め手 |
| --- | --- | --- |
| 2点間の長さ、線分を分ける点 | 距離の公式、内分・外分 | 座標の差を2乗して足す／比に応じて混ぜる |
| 通る1点と傾き、2点を通る直線 | 直線の方程式 | $y - y_1 = m(x - x_1)$、$ax + by + c = 0$ |
| 平行・垂直、2直線の交点 | 傾きの比較と連立 | $m_1 = m_2$、$m_1 m_2 = -1$ |
| 中心・半径、円の方程式 | 円の方程式 | $(x - a)^2 + (y - b)^2 = r^2$、平方完成 |
| 円と直線の共有点、接線 | 中心と直線の距離 $d$ と半径 $r$ | $d < r$ で2個、$d = r$ で接する、$d > r$ で0個 |
| 条件を満たす点の集まり | 軌跡 | $P(x, y)$ とおき、条件を距離の式にする |
| 不等式の表す広がり | 領域 | 境界線を引き、試しの点で側を決める |
| 領域内での最大・最小 | 領域と最大・最小 | 目的の式を $k$ とおき、直線や円が領域に接する位置を調べる |

<Why>
判断表を順に試す前に「求めるものは点か、集合か」を決めるのは、点と集合では条件の扱い方が変わるからです。点の座標を求める問題では条件が等式になり、連立や代入で解けます。一方、点の集合を求める問題では条件を等式・不等式のまま残し、それが表す図形を読み取ります。数学Iの二次関数で最大・最小を求めたとき、式を平方完成して頂点を読んだのも、「答えを直接計算する」のではなく「式の形から図形的な意味を読む」ためでした。この章の総仕上げでも、点が動く範囲と式の表す円を重ねて読むことが決め手になります。
</Why>

## 確認問題 — 道具を混ぜて解く

<Practice title="確認問題1 — 距離と直線">
2点 $A(-1, 2)$、$B(3, 4)$ を通る直線 $\ell$ がある。原点 $O$ から直線 $\ell$ までの距離を求めよ。

<Reveal label="解答">
直線の傾きは $\dfrac{4 - 2}{3 - (-1)} = \dfrac{1}{2}$。点 $A$ を使って $y - 2 = \dfrac{1}{2}(x + 1)$、整理すると $x - 2y + 5 = 0$。

一般形 $ax + by + c = 0$ と点 $(x_0, y_0)$ の距離は $\dfrac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$ なので、原点からの距離は

$$
\frac{|0 - 0 + 5|}{\sqrt{1^2 + (-2)^2}} = \frac{5}{\sqrt{5}} = \sqrt{5}
$$

よって $\sqrt{5}$。
</Reveal>
</Practice>

<Practice title="確認問題2 — 距離と軌跡">
2点 $A(-3, 0)$、$B(3, 0)$ に対して、$AP^2 + BP^2 = 40$ を満たす点 $P$ の軌跡を求めよ。

<Reveal label="解答">
点 $P$ を $(x, y)$ とおく。$AP^2 = (x + 3)^2 + y^2$、$BP^2 = (x - 3)^2 + y^2$ なので

$$
(x + 3)^2 + y^2 + (x - 3)^2 + y^2 = 40
$$

左辺を整理すると $2x^2 + 2y^2 + 18 = 40$、すなわち $x^2 + y^2 = 11$。よって軌跡は、原点を中心とする半径 $\sqrt{11}$ の円。
</Reveal>
</Practice>

<Practice title="確認問題3 — 領域と1次式の最大">
連立不等式 $x \ge 0$、$y \ge 0$、$x + y \le 4$ の表す領域を $D$ とする。(1) $D$ はどのような図形か。(2) $D$ 内で $x + 2y$ が最大となる点と、その最大値を求めよ。

<Reveal label="解答">
(1) 境界線は3直線 $x = 0$、$y = 0$、$x + y = 4$。これらの交点は $(0, 0)$、$(4, 0)$、$(0, 4)$ なので、$D$ はこの3点を頂点とする三角形の周および内部。

(2) $x + 2y = k$ とおくと $y = -\dfrac{1}{2}x + \dfrac{k}{2}$。この直線を傾き $-\dfrac{1}{2}$ のまま動かし、$D$ と共有点をもつぎりぎりまで $k$ を大きくすると、点 $(0, 4)$ を通る。最大値は $0 + 2 \cdot 4 = 8$（各頂点での値 $(0, 0) \to 0$、$(4, 0) \to 4$、$(0, 4) \to 8$ を比べてもよい）。
</Reveal>
</Practice>

## 発展問題 — 領域での2次式の最大・最小

<WorkedExample title="発展: 領域と x² + y² - 2x - 2y">
連立不等式 $x \ge 0$、$y \ge 0$、$x + y \le 4$ の表す領域を $D$ とする。点 $P(x, y)$ が $D$ 内を動くとき、$x^2 + y^2 - 2x - 2y$ の最大値と最小値、およびそれらを与える点の座標を求めよ。

<Steps>
<Step reason="2乗の和を含む式は、ある点からの距離の2乗として読めるので、平方完成して形をそろえます。">$x^2 + y^2 - 2x - 2y = (x - 1)^2 + (y - 1)^2 - 2$。この式の値は、点 $C(1, 1)$ からの距離の2乗から $2$ を引いたものです。</Step>
<Step reason="最小値は C に最も近い点で距離が最小になるときです。まず C が領域の内部にあるかを確かめます。">$C(1, 1)$ は $1 \ge 0$、$1 \ge 0$、$1 + 1 = 2 \le 4$ を満たすので $D$ の内部にある。したがって距離の最小は $0$、最小値は $0 - 2 = -2$。与える点は $C$ 自身、すなわち $(1, 1)$。</Step>
<Step reason="最大は C から最も遠い点で起こります。距離の2乗は各辺の上で端点のどちらかで最大になるので、3頂点だけ調べれば十分です。">$C$ と3頂点の距離の2乗を比べる。$(0, 0)$ では $1^2 + 1^2 = 2$、$(4, 0)$ では $3^2 + 1^2 = 10$、$(0, 4)$ では $1^2 + 3^2 = 10$。最大は $10$ なので、式の最大値は $10 - 2 = 8$。</Step>
<Step reason="距離が最大になる頂点が2つあるので、最大値を与える点も2つあります。">最大値は $8$。与える点は $(4, 0)$ と $(0, 4)$。</Step>
</Steps>

<Answer>
最大値 $8$（$(4, 0)$ と $(0, 4)$ でとる）、最小値 $-2$（$(1, 1)$ でとる）。
</Answer>
</WorkedExample>

  options={['点 C(1, 1) からの距離の2乗として読むため', '2乗の項を消して1次式にするため', '領域 D の頂点を求めるため']}

/>

<Misconception>
<Wrong>
$x^2 + y^2 - 2x - 2y$ の最小値も、1次式のときと同じように領域の頂点でとるはずだ。3頂点 $(0, 0)$、$(4, 0)$、$(0, 4)$ での値を比べればよい。
</Wrong>
<WhyWrong>
3頂点での値は $0$、$8$、$8$ で、いずれも $(1, 1)$ での値 $-2$ より大きい。1次式 $x + 2y$ の最大・最小は領域の頂点でとりますが、2乗を含む式では、最小が頂点でも辺の上でもなく、領域の内部の点で起こることがあります。頂点の値だけを比べると、最小値 $-2$ を取り逃します。
</WhyWrong>
<Right>
平方完成して中心 $C(1, 1)$ を求めたら、まず $C$ が領域の内部にあるかを確かめます。内部にあれば距離の最小は $0$ で、最小値は $C$ でとります。最大は $C$ から最も遠い頂点（または辺の端）で調べます。
</Right>
</Misconception>

<CheckUnderstanding>
(1) 2点 $A(-2, 3)$、$B(1, 7)$ の距離 $AB$ を求めよ。

(2) 円 $x^2 + y^2 = 13$ 上の点 $(2, 3)$ における接線の方程式を求めよ。

(3) 不等式 $y < 2x + 3$ の表す領域は、境界線の上側と下側のどちらか。また、境界線は実線と破線のどちらでかくか。

<Reveal label="答え">
(1) x の差は $3$、y の差は $4$ なので $AB = \sqrt{3^2 + 4^2} = 5$。

(2) $x_1 = 2$、$y_1 = 3$、$r^2 = 13$ より $2x + 3y = 13$。

(3) 点 $(0, 0)$ を代入すると $0 < 3$ は真なので、原点を含む下側。等号がないので境界線は破線。
</Reveal>
</CheckUnderstanding>

<Practice title="仕上げの練習 — 中心が領域の外にあるとき">
連立不等式 $x \ge 0$、$y \ge 0$、$x + y \le 2$ の表す領域を $E$ とする。点 $P(x, y)$ が $E$ 内を動くとき、$x^2 + y^2 - 4x - 2y$ の最大値と最小値、およびそれらを与える点の座標を求めよ。

<Reveal label="解答">
$x^2 + y^2 - 4x - 2y = (x - 2)^2 + (y - 1)^2 - 5$。中心 $C(2, 1)$ は $2 + 1 = 3 > 2$ なので $E$ の外にある。

最小は、$E$ の中で $C$ に最も近い点で起こる。$x + y = 2$ に垂直で $C(2, 1)$ を通る直線は傾き $1$ で $y = x - 1$。これと $x + y = 2$ の交点は $\left(\dfrac{3}{2}, \dfrac{1}{2}\right)$ で、$E$ の辺の上にある。$C$ からの距離の2乗は $\left(\dfrac{1}{2}\right)^2 + \left(\dfrac{1}{2}\right)^2 = \dfrac{1}{2}$ なので、最小値は $\dfrac{1}{2} - 5 = -\dfrac{9}{2}$。

最大は頂点で調べる。$(0, 0)$ では $0$、$(2, 0)$ では $-4$、$(0, 2)$ では $0$。よって最大値は $0$ で、与える点は $(0, 0)$ と $(0, 2)$。
</Reveal>
</Practice>
