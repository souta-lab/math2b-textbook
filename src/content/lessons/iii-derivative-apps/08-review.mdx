<Hook>
この単元では、接線・法線、平均値の定理、増減と極値、凹凸と変曲点、グラフの概形、最大最小、方程式・不等式、速度と変化率を学びました。ばらばらに見えるこれらの道具は、すべて「関数を微分してその振る舞いを読む」という1つの流れに属しています。入試の総合問題は、この流れをどこでどの順に使うかを問うてきます。
</Hook>

<Prediction
  question="f(x) = x + cos x は極値をもつ？"
  options={['もたない', '極大をもつ', '極小をもつ']}
  answer="もたない"
  explanation="f′(x)=1−sin x は、sin x≤1 より常に 0 以上です。f′(x)=0 となる点はあっても符号は負になりえず、増加から減少へ変わる場所がありません。だから極値をもちません。"
/>

関数を調べる流れをもう一度確認します。まず定義域と端での極限、次に $f'(x)$ の符号で増減、$f''(x)$ の符号で凹凸。この3層を重ねると概形が決まり、そこから最大最小や実数解の個数が読み取れます。どの問題でも、この同じ手順を必要な深さまで実行するだけです。

<Why>
総合問題では、すべての道具を使う必要はありません。問いが「接線」ならまず微分係数、「実数解の個数」ならグラフと水平線の交点、「最大最小」なら候補の列挙、と目的から逆算して道具を選びます。闇雲に微分を繰り返すのではなく、何を知りたいのかを先に決めることが、短時間で正確に解く鍵になります。
</Why>

<WorkedExample title="総合例題: 積の形の関数の最大最小">
$0\le x\le 2\pi$ において $f(x)=e^{-x}\sin x$ の最大値と最小値を求めなさい。

<Steps>
<Step reason="最大最小の候補を求めるため、まず導関数を計算します。">$f'(x)=-e^{-x}\sin x+e^{-x}\cos x=e^{-x}(\cos x-\sin x)$。</Step>
<Step reason="e^{-x} は常に正なので、符号を決めるのは cos x − sin x です。">$e^{-x}>0$ より、符号は $\cos x-\sin x$ で決まる。</Step>
<Step reason="符号が変わる候補として f′(x)=0 を解きます。">$\cos x=\sin x$ より $\tan x=1$。$0\le x\le 2\pi$ では $x=\dfrac{\pi}{4},\ \dfrac{5\pi}{4}$。</Step>
<Step reason="各区間での符号を調べ、極大・極小を判定します。">$0<x<\dfrac{\pi}{4}$ で正、$\dfrac{\pi}{4}<x<\dfrac{5\pi}{4}$ で負、$\dfrac{5\pi}{4}<x<2\pi$ で正。よって $x=\dfrac{\pi}{4}$ で極大、$x=\dfrac{5\pi}{4}$ で極小。</Step>
<Step reason="閉区間の最大最小は端点も候補なので、極値と端点の値を比べます。">$f\!\left(\dfrac{\pi}{4}\right)=\dfrac{1}{\sqrt2}e^{-\pi/4}$、$f\!\left(\dfrac{5\pi}{4}\right)=-\dfrac{1}{\sqrt2}e^{-5\pi/4}$、$f(0)=f(2\pi)=0$。</Step>
<Step reason="正の極大と負の極小、端点 0 を比べて最大と最小を確定します。">正の極大が最大、負の極小が最小となる。</Step>
</Steps>

<Answer>
最大値 $\dfrac{1}{\sqrt2}e^{-\pi/4}$（$x=\dfrac{\pi}{4}$）、最小値 $-\dfrac{1}{\sqrt2}e^{-5\pi/4}$（$x=\dfrac{5\pi}{4}$）。
</Answer>
</WorkedExample>

<Misconception>
<Wrong>
微分して $f'(x)=0$ となる点を求めたので、その点はすべて極値であり、極値の中で一番大きいものが最大値である。
</Wrong>
<WhyWrong>
2つの誤りが重なっています。第一に、$f'(x)=0$ でも符号が変わらなければ極値ではありません。$f(x)=x+\cos x$ は $f'(x)=1-\sin x\ge 0$ で、$f'(x)=0$ となる点はあっても極値をもちません。第二に、極値は内部の山や谷であり、最大最小は端点でもとります。極値だけを比べると端点を落とします。
</WhyWrong>
<Right>
$f'(x)=0$ は極値の候補にすぎず、前後での符号変化を確認する。最大最小は極値と区間の端点（および微分できない点）をすべて比較して決める。
</Right>
</Misconception>

<CheckUnderstanding>
（1）曲線 $y=\log x$ の $x=1$ における接線と法線の方程式を求めなさい。
<Reveal label="答え">
$y'=\dfrac1x$ より傾きは $1$。$y(1)=0$ だから接線は $y=x-1$。法線は傾き $-1$ で、$y=-(x-1)=-x+1$。
</Reveal>

（2）方程式 $x^3-3x=1$ の異なる実数解の個数を求めなさい。
<Reveal label="答え">
$f(x)=x^3-3x$ の極大値 $2$、極小値 $-2$ より、$1$ は両者の間にある。よって水平線 $y=1$ との共有点は3個で、実数解は3個。
</Reveal>
</CheckUnderstanding>

<Practice title="章末演習（道具の選び分け）">
（1）曲線 $y=e^x\cos x$ の $x=0$ における接線と法線の方程式を求めなさい。

（2）方程式 $xe^{-x}=\dfrac14$ の異なる実数解の個数を求めなさい。

（3）位置 $x(t)=t^3-6t^2+9t$ について、速度が $0$ になる時刻と、その各時刻における加速度を求めなさい。

（4）区間 $[1,\ 4]$ において $f(x)=x+\dfrac{9}{x}$ の最大値と最小値を求めなさい。

<Reveal label="解答">
（1）$y'=e^x\cos x-e^x\sin x=e^x(\cos x-\sin x)$。$x=0$ で傾きは $1$、$y(0)=1$。接線は $y-1=x$、すなわち $y=x+1$。法線は傾き $-1$ で $y=-x+1$。

（2）$f(x)=xe^{-x}$ は $x=1$ で最大値 $\dfrac1e$ をとる。$\dfrac14<\dfrac1e$ かつ $\dfrac14>0$ なので、$x>0$ の範囲で2個の実数解をもつ（$x<0$ では $f<0$ で解なし）。よって2個。

（3）$v(t)=x'(t)=3t^2-12t+9=3(t-1)(t-3)$ より、$v(t)=0$ となるのは $t=1,\ 3$。$a(t)=v'(t)=6t-12$ なので、$a(1)=-6$、$a(3)=6$。

（4）$f'(x)=1-\dfrac{9}{x^2}=0$ より $x=3$。$f(1)=1+9=10$、$f(3)=3+3=6$、$f(4)=4+\dfrac94=\dfrac{25}{4}$。よって最大値 $10$（$x=1$）、最小値 $6$（$x=3$）。
</Reveal>
</Practice>
