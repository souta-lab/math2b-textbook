## 掛けてずらして引く

前のレッスンで、等比数列の第 $n$ 項が $a r^{n-1}$ であることを学びました。ここではその和 $S_n = a + ar + ar^2 + \dots + ar^{n-1}$ を求めます。等差数列では項を対にして同じ値を作りましたが、等比数列では掛け算で項をずらすと、多くの項が重なって消えます。

<Why>
和 $S_n$ に公比 $r$ を掛けると、各項が1つ右へずれて $ar + ar^2 + \dots + ar^n$ になる。この $rS_n$ を元の $S_n$ から引くと、中央の項がそっくり打ち消し合い、端の $a$ と $ar^n$ だけが残る。等差では「足して対にする」ことで中間を消したが、等比では「掛けてずらして引く」ことで中間を消す。ここが和の公式を導く最短の道である。
</Why>

<Steps>
<Step reason="求める和を文字でおき、両辺に公比を掛けた式を用意するためです。">$S_n = a + ar + ar^2 + \dots + ar^{n-1}$ とおく。</Step>
<Step reason="公比を掛けると、各項が1つ右の項に重なります。">両辺に $r$ を掛けると $rS_n = ar + ar^2 + \dots + ar^{n-1} + ar^n$。</Step>
<Step reason="引き算すると中央の共通部分が打ち消し合い、端の2項だけが残ります。">辺々を引くと $S_n - rS_n = a - ar^n$。</Step>
<Step reason="左辺を S_n でくくり、r≠1 のときに両辺を 1−r で割れば和が求まります。">$(1-r)S_n = a(1-r^n)$ より、$r\ne1$ のとき $S_n = \dfrac{a(1-r^n)}{1-r}$。</Step>
</Steps>

<Theorem name="等比数列の和">
初項 $a$、公比 $r$ の等比数列の初項から第 $n$ 項までの和 $S_n$ は、$r\ne1$ のとき
$$
S_n = \dfrac{a(1-r^n)}{1-r} = \dfrac{a(r^n-1)}{r-1}
$$
であり、$r=1$ のときは各項がすべて $a$ なので
$$
S_n = na
$$
である。
</Theorem>

<Note type="warn">
$r\ne1$ という条件は、公式の分母 $1-r$ が0にならないためのものです。公比が1の等比数列は $a,\ a,\ a,\ \dots$ という定数の並びになるので、和は項数×初項、つまり $na$ で求めます。
</Note>

和のグラフでは、n が1増えるごとに増える量そのものが倍になっていきます。これが、等差数列の和がなだらかに増えるのとの決定的な違いです。

<WorkedExample title="例題1: 和の公式をそのまま使う">
初項3、公比2の等比数列について、初項から第5項までの和 $S_5$ を求めよ。

<Steps>
<Step reason="公比が1ではないので、r≠1 の和の公式をそのまま使えます。">$S_5 = \dfrac{3(2^5-1)}{2-1}$。</Step>
<Step reason="分母が1なので、かっこの中だけを計算すればよいです。">$2^5 = 32$ より $S_5 = 3\times(32-1)$。</Step>
<Step reason="31を3倍すれば和が求まります。">$S_5 = 93$。</Step>
</Steps>

<Answer>
$S_5 = 93$
</Answer>
</WorkedExample>

<WorkedExample title="例題2: 末項から項数を求めて和を計算する">
等比数列 $3,\ 6,\ 12,\ \dots,\ 384$ の初項から末項までの和を求めよ。

<Steps>
<Step reason="和の公式には項数 n が必要なので、まず一般項に末項384を当てはめて n を求めます。">$3\times2^{\,n-1} = 384$ より $2^{\,n-1} = 128$。</Step>
<Step reason="128は2の7乗なので、指数を比べれば項数が分かります。">$n-1 = 7$ より $n = 8$。</Step>
<Step reason="項数が分かったので、和の公式に初項・公比・n を代入します。">$S_8 = \dfrac{3(2^8-1)}{2-1}$。</Step>
<Step reason="2の8乗は256なので、引いて3倍します。">$S_8 = 3\times(256-1) = 765$。</Step>
</Steps>

<Answer>
$S_8 = 765$
</Answer>
</WorkedExample>

<SelfExplanation
  prompt="等比数列の和では、なぜ公比を掛けてから引くの？"
  options={['掛けてずらすと中間の項が重なって消えるから', '公比がいつも1より大きいから', '和が必ず整数になるから']}
  model="S_n に公比を掛けると各項が1つ右へずれます。元の式から引くと中央の項がそっくり打ち消し合い、端の2項だけが残ります。その結果を 1−r で割れば和が求まります。"
/>

<Misconception>
<Wrong>
公比が1のときも、和の公式 $S_n = \dfrac{a(1-r^n)}{1-r}$ をそのまま使える。
</Wrong>
<WhyWrong>
$r=1$ を代入すると分母が $1-1=0$ となり、0で割ることになる。この式変形の途中で両辺を $1-r$ で割っており、$r=1$ ではその操作が許されない。公式が使えないのは計算ミスではなく、式変形の前提が崩れるからである。
</WhyWrong>
<Right>
公比が1のときは、各項がすべて初項 $a$ と等しいので $S_n = na$。$r\ne1$ のときだけ公式を使う。
</Right>
</Misconception>

<Misconception>
<Wrong>
等比数列の和の公式は $S_n = \dfrac{a(r^{\,n-1}-1)}{r-1}$ である。
</Wrong>
<WhyWrong>
引き算の結果は $a-ar^n = a(1-r^n)$ であり、指数は $n$ であって $n-1$ ではない。第 $n$ 項は $ar^{n-1}$ だが、和には初項から第 $n$ 項までが含まれ、最後の引き算で現れるのは $ar^n$ である。指数を $n-1$ にすると、末項の1つ手前までしか足していないことになる。
</WhyWrong>
<Right>
和の公式の指数は $n$。$S_n = \dfrac{a(1-r^n)}{1-r} = \dfrac{a(r^n-1)}{r-1}$（$r\ne1$）。
</Right>
</Misconception>

<CheckUnderstanding>
(1) 初項2、公比3の等比数列の初項から第4項までの和を求めよ。
<Reveal label="答え">
公比が1ではないので $S_4 = \dfrac{2(3^4-1)}{3-1} = \dfrac{2\times80}{2} = 80$。実際に $2+6+18+54=80$ でも確かめられる。
</Reveal>

(2) 公比が1である等比数列の和は、どのように求めるか。
<Reveal label="答え">
公比が1のときは各項がすべて初項 $a$ に等しい。したがって $S_n = na$。分母が0になる和の公式は使わない。
</Reveal>
</CheckUnderstanding>

<Practice title="まとめの練習（等差・等比）">
(1) 初項 $-2$、公差 $4$ の等差数列の第15項と、初項から第15項までの和を求めよ。
(2) 初項1、公比3の等比数列の第5項と、初項から第5項までの和を求めよ。
(3) 等比数列 $4,\ 2,\ 1,\ \dfrac{1}{2},\ \dots$ の初項から第6項までの和を求めよ。
<Reveal label="解答">
(1) $a_{15} = -2+14\times4 = 54$。$S_{15} = \dfrac{15(-2+54)}{2} = \dfrac{15\times52}{2} = 390$。
(2) $a_5 = 1\times3^4 = 81$。$S_5 = \dfrac{3^5-1}{3-1} = \dfrac{243-1}{2} = 121$。
(3) 初項4、公比 $\dfrac{1}{2}$。$S_6 = \dfrac{4\left(1-\left(\frac{1}{2}\right)^6\right)}{1-\frac{1}{2}} = \dfrac{4\times\frac{63}{64}}{\frac{1}{2}} = \dfrac{63}{8}$。
</Reveal>
</Practice>
