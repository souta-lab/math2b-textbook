## 隣との関係で数列を決める

これまでは一般項を直接求めてきました。ここでは、隣り合う項の関係だけが先に分かっていて、そこから一般項を導く場面を考えます。関係が「差が一定」なら等差数列、「比が一定」なら等比数列として、すでに学んだ形に還元できます。

<Definition term="漸化式（二項間）">
隣り合う2つの項の関係式と、初項を組にして数列を定めるとき、その関係式を漸化式という。たとえば
$$
a_1 = c, \qquad a_{n+1} = f(a_n)
$$
のように書く。二項間とは、$a_{n+1}$ と $a_n$ の2項だけの関係という意味である。
</Definition>

<Why>
漸化式を使うのは、一般項を直接書けない現象でも、隣との関係なら書けることが多いからだ。複利や個体数の増加のように「前の状態から次の状態が決まる」現象は、漸化式の形で自然に表せる。逆に、漸化式が得られれば、関係の形を見て等差・等比に翻訳し、一般項へ戻せる。求めたいのは、いつでも計算できる一般項である。
</Why>

## 等差・等比として読める漸化式

<Theorem name="等差・等比になる漸化式">
$d$、$r$ を定数とすると、
- $a_{n+1} = a_n + d$ なら、数列は公差 $d$ の等差数列で、$a_n = a_1 + (n-1)d$。
- $a_{n+1} = r a_n$ なら、数列は公比 $r$ の等比数列で、$a_n = a_1\,r^{\,n-1}$。
</Theorem>

隣との差が一定なら等差数列、隣との比が一定なら等比数列です。漸化式を見た瞬間に、この2つのどちらかへ持ち込めないかを考えます。

## 等比に持ち込めない漸化式

いちばん困るのは $a_{n+1}=2a_n+1$ のように、掛ける操作と足す操作が混ざった形です。この形は、うまい定数を引くと等比数列に変わります。

<Why>
$a_{n+1}=p a_n+q$ が等比とみなせないのは、$+q$ のぶんだけ比が一定にならないからだ。そこで「何度繰り返しても値が変わらない項」を基準に考える。それが方程式 $c = pc+q$ を満たす定数 $c$ で、不動点とよばれる。各項から $c$ を引いて変化分だけを見ると、$a_{n+1}-c = p(a_n-c)$ となり、$+q$ が消えて純粋な等比の形になる。
</Why>

<Steps>
<Step reason="繰り返しても変わらない基準の値 c を求めたいので、a_{n+1}=a_n=c とおきます。">$c = pc+q$ を解くと $(1-p)c = q$ より $c = \dfrac{q}{1-p}$（$p\ne1$）。</Step>
<Step reason="各項から基準点 c を引いた差が、等比の形になるかを確かめます。">$b_n = a_n - c$ とおく。$b_{n+1} = a_{n+1}-c = p a_n+q-c = p(a_n-c) = p\,b_n$。</Step>
<Step reason="b_n は公比 p の等比数列になったので、等比の一般項を当てはめれば a_n が求まります。">$b_n = b_1\,p^{\,n-1}$ より $a_n = c + (a_1-c)\,p^{\,n-1}$。</Step>
</Steps>

<WorkedExample title="例題1: 等差・等比として解く">
次の漸化式で定まる数列の一般項を求めよ。
(1) $a_1=3$、$a_{n+1}=a_n+4$
(2) $a_1=2$、$a_{n+1}=3a_n$

<Steps>
<Step reason="隣との差が一定なので、等差数列の一般項を使えます。">(1) $a_n = a_1+(n-1)d = 3+4(n-1) = 4n-1$。</Step>
<Step reason="第10項は一般項に n=10 を代入すれば求まります。">$a_{10} = 4\times10-1 = 39$。</Step>
<Step reason="隣との比が一定なので、等比数列の一般項を使えます。">(2) $a_n = a_1\,r^{\,n-1} = 2\times3^{\,n-1}$。</Step>
<Step reason="指数が 5−1=4 なので、3を4回掛けます。">$a_5 = 2\times3^4 = 2\times81 = 162$。</Step>
</Steps>

<Answer>
(1) $a_n = 4n-1$　(2) $a_n = 2\times3^{n-1}$
</Answer>
</WorkedExample>

<WorkedExample title="例題2: 定数を引いて等比に置き換える">
$a_1=1$、$a_{n+1}=2a_n+1$ で定まる数列の一般項を求めよ。

<Steps>
<Step reason="掛ける操作と足す操作が混ざっているので、繰り返しても変わらない基準の値を求めます。">$c = 2c+1$ を解くと $c = -1$。</Step>
<Step reason="各項から基準点 c を引くと、足し算が消えて等比の関係だけが残ります。">$b_n = a_n+1$ とおくと、$b_{n+1} = 2b_n$。</Step>
<Step reason="b_n は公比2の等比数列で、初項は b_1=a_1+1=2 です。">$b_n = 2\times2^{\,n-1} = 2^n$。</Step>
<Step reason="b_n=a_n+1 を a_n について解けば、もとの数列の一般項に戻ります。">$a_n = b_n-1 = 2^n-1$。</Step>
</Steps>

<Answer>
$a_n = 2^n-1$（$a_1=1$、$a_2=3$、$a_3=7$ と確かめられる）
</Answer>
</WorkedExample>

  options={['基準点をずらすと等比の関係だけが残るから', '足し算を消せば項数が減るから', '初項が1だから']}
  model="繰り返しても変わらない値 c=−1 が基準です。b_n=a_n+1 とおくと、b_{n+1}=2b_n となり、足し算が消えて純粋な等比になります。あとは等比の一般項を求めて、a_n=b_n−1 で戻します。"
/>

<Misconception>
<Wrong>
$a_{n+1}=2a_n+1$ は等比数列だから、一般項は $a_n = a_1\times2^{\,n-1}$ である。
</Wrong>
<WhyWrong>
$a_1=1$ とすると、$a_2=2\times1+1=3$ であり、$a_1\times2 = 2$ と一致しない。$a_1=1$、$a_2=3$、$a_3=7$ の比は $3$、$7/3$ と一定ではなく、等比数列ではない。$+1$ のぶんだけ比がずれるので、そのまま等比の一般項を当てはめることはできない。
</WhyWrong>
<Right>
$a_{n+1}=2a_n+1$ は、$b_n=a_n+1$ とおくと $b_{n+1}=2b_n$ という等比の形になる。$b_n=2^n$ から $a_n=2^n-1$ が得られる。
</Right>
</Misconception>

<CheckUnderstanding>
(1) $a_1=5$、$a_{n+1}=a_n-2$ で定まる数列の一般項と第10項を求めよ。
<Reveal label="答え">
公差 $-2$ の等差数列なので $a_n = 5-2(n-1) = -2n+7$。第10項は $a_{10}=-2\times10+7=-13$。
</Reveal>

(2) $a_1=4$、$a_{n+1}=-2a_n$ で定まる数列の一般項と第5項を求めよ。
<Reveal label="答え">
公比 $-2$ の等比数列なので $a_n = 4\times(-2)^{n-1}$。第5項は $a_5 = 4\times(-2)^4 = 4\times16 = 64$。
</Reveal>

(3) $a_1=3$、$a_{n+1}=2a_n-3$ で定まる数列の一般項を求めよ。
<Reveal label="答え">
$c=2c-3$ より $c=3$。$b_n=a_n-3$ とおくと $b_{n+1}=2b_n$ で、$b_1=a_1-3=0$。よってすべての $n$ で $b_n=0$、すなわち $a_n=3$（定数の並び $3,\ 3,\ 3,\ \dots$）。
</Reveal>
</CheckUnderstanding>
