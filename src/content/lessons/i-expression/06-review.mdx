<Hook>
道具が増えるほど、選び間違えたときの遠回りも長くなる。この章では、展開の型、因数分解、実数と根号、有理化、一次不等式、絶対値を学んだ。道具は出そろっている。章末で試されるのは、問題を見た瞬間に「どの道具を、どの順で使うか」を決める力だ。
</Hook>

<Prediction
  question="方程式 $|x-1|=4$ を解くとき、最初に使う一手はどれでしょう？"
  options={['x-1=4 とする', 'x-1=±4 とする', '両辺を2乗する']}
  answer="x-1=±4 とする"
  explanation="絶対値が付いた式は、中身が正の場合と負の場合の両方を調べます。$x-1=4$ だけでは $x=5$ しか出ず、$x=-3$ を取りこぼします。両辺を2乗すると同値でない変形になり、余計な解や抜けが生じます。"
/>

この単元の道具を、問題文の合図から引けるように整理しよう。求める量を最短で与える道具を最初に選ぶのが原則である。

| 問題の形 | 最初に使う道具 | 合図になる言葉 |
|---|---|---|
| かっこの展開、同じまとまりが2回 | 乗法公式と置き換え | 「展開せよ」、共通部分 |
| 2次式、共通因数、4次式 | 因数分解（たすき掛け・置き換え） | 「因数分解せよ」、積の形にしたい |
| 2乗を含む根号 | 根号と絶対値の性質 | 「簡単にせよ」、中身の2乗 |
| 分母に根号 | 共役を掛けて有理化 | 分母が $\sqrt a\pm\sqrt b$ |
| 1次の不等式 | 移項と、割る数の符号 | 「範囲を求めよ」、$x\lt$ の係数が負 |
| 絶対値の方程式・不等式 | 点との距離としての $\pm$ | 距離、場合分け |
| 対称式の値 | $x+\dfrac1x$ や $a+b$、$ab$ を作る | 解を求めずに和と積を問う |

選択の原則は、求める量から逆算することだ。余りや範囲だけを問われたら、途中の値を全部求める必要はない。次に、式の形をそろえる。同じまとまり、同じ根号、同じ係数を探し、1文字に置くか共役を掛ける。最後に、場合分けの抜けを点検する。絶対値と、文字で割る不等式がその代表である。

<Why>
章末で「どの道具か」を先に決めるのは、計算を始めてから方針を変えると、それまでの式変形が無駄になるからだ。たとえば対称式 $a^2-ab+b^2$ は、$a$ と $b$ を1つずつ根号のまま2乗すると根号が入り乱れる。先に $a+b$ と $ab$ を作ると決めておけば、$(a+b)^2-3ab$ の形にはめられ、根号は最後に1回だけ現れる。数学Iで「因数分解できるなら解の公式を使わない」と選んだのと同じ判断である。
</Why>

<KeyPoint>
章末問題は、公式を1つ当てはめる問題ではない。「何を求めるか」を読み、その量を最短で与える道具を選び、足りなければ次の道具につなぐ。1つの問題の中で、置き換え・有理化・対称式が順番に働く。
</KeyPoint>

<WorkedExample title="発展（入試風）: 2変数の因数分解と対称式">
次の問いに答えよ。

(1) $x^2+3xy+2y^2-x-3y-2$ を因数分解せよ。

(2) $a=\sqrt5+2$、$b=\sqrt5-2$ のとき、$a^2-ab+b^2$ の値を求めよ。

<Steps>
<Step reason="(1) は2文字あるので、次数が低い方の文字 $x$ について降べきの順に整理する。定数部分は $y$ の式としてまとめておく。">$x$ で整理すると $x^2+(3y-1)x+(2y^2-3y-2)$。</Step>
<Step reason="定数部分 $2y^2-3y-2$ を $y$ について因数分解する。積が $-2$、和が $-3$ になる組を探す。">$2y^2-3y-2=(2y+1)(y-2)$。</Step>
<Step reason="$(x+a)(x+b)$ の形にできるか確かめる。$x$ の係数 $3y-1$ が、2つの因数の和 $(2y+1)+(y-2)=3y-1$ と一致する。">$x^2+(3y-1)x+(2y+1)(y-2)=(x+2y+1)(x+y-2)$。</Step>
<Step reason="(2) は $a$ と $b$ を直接2乗すると根号が混じる。和と積を作れば、対称式は根号を含まない式に書き換えられる。まず $ab$ と $a+b$ を求める。">$ab=(\sqrt5+2)(\sqrt5-2)=5-4=1$、$a+b=2\sqrt5$。</Step>
<Step reason="$a^2-ab+b^2=a^2+2ab+b^2-3ab=(a+b)^2-3ab$ と変形して、和と積だけの式にする。">$(a+b)^2-3ab=(2\sqrt5)^2-3\cdot1$。</Step>
<Step reason="計算する。$(2\sqrt5)^2=4\cdot5=20$ なので $20-3=17$。$a$、$b$ を代入した答えと比べても、根号が消えて整数になる点が整合する。">$20-3=17$。</Step>
</Steps>

<Answer>
(1) $(x+2y+1)(x+y-2)$　(2) $17$
</Answer>
</WorkedExample>

<Misconception>
<Wrong>
章末の発展問題は、この章で覚えた公式を1つ選んで当てはめれば解ける。
</Wrong>
<WhyWrong>
発展問題では複数の道具が順番に現れる。たとえば $a^2-ab+b^2$ は、$a$ と $b$ の値を求めてから代入するだけでは根号の計算が重く、途中で符号を落としやすい。和と積を作って対称式に直す一手を挟んで初めて、短く正確に届く。1つの公式では答えに至らない。
</WhyWrong>
<Right>
発展問題は、使える事実を並べ、求める量に届く順路を選ぶ問題である。各手順が何を与えるかを言えるようにしておけば、初めて見る問題でも道具の組合せを設計できる。
</Right>
</Misconception>

<CheckUnderstanding>
（1）2変数の式を因数分解するとき、最初に何をすればよいか。
<Reveal label="答え">
次数が低い方の文字について降べきの順に整理する。定数部分をその文字について因数分解し、1次の係数が因数の和と一致するかを確かめれば、$(x+a)(x+b)$ の形に持ち込める。
</Reveal>

（2）$a^2-ab+b^2$ を $a+b$ と $ab$ だけで表せ。
<Reveal label="答え">
$a^2-ab+b^2=a^2+2ab+b^2-3ab=(a+b)^2-3ab$。
</Reveal>

（3）$\sqrt{a^2}$ を簡単にするとき、最初に確かめるべきことは何か。
<Reveal label="答え">
中身 $a$ の符号を確かめる。$a\ge0$ なら $\sqrt{a^2}=a$、$a\lt0$ なら $\sqrt{a^2}=-a$。まとめて $\sqrt{a^2}=|a|$ と書ける。
</Reveal>
</CheckUnderstanding>

<Practice title="確認問題（単元を横断）">
（1）$2x^2+3x-2$ を因数分解せよ。

（2）$|x+3|\ge5$ を解け。

（3）$\sqrt{9+4\sqrt2}$ を簡単にせよ。

（4）$x=\sqrt5+\sqrt3$、$y=\sqrt5-\sqrt3$ のとき、$x^2+y^2$ の値を求めよ。

<Reveal label="解答">
（1）たすき掛けで $(2x-1)(x+2)$。斜めの和は $4x-x=3x$ で一致する。

（2）$x+3\ge5$ または $x+3\le-5$。よって $x\ge2$ または $x\le-8$。

（3）$4\sqrt2=2\sqrt8$ より $\sqrt{9+2\sqrt8}$。和が $9$、積が $8$ になる2数は $1$ と $8$ なので、$\sqrt1+\sqrt8=1+2\sqrt2$。

（4）$x+y=2\sqrt5$、$xy=(\sqrt5)^2-(\sqrt3)^2=5-3=2$。$x^2+y^2=(x+y)^2-2xy=20-4=16$。
</Reveal>
</Practice>
