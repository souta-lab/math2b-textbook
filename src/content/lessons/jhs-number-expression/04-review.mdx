<Hook>
入試の計算問題は、1つの分野だけで出ることは少ない。符号を処理し、かっこを外し、指数をまとめ、根号を整理する、という一連の流れが1問の中に詰まっている。速い人は、各段階で「次に何をすべきか」をいちいち考えずに手が動く。この章の締めくくりとして、4つの型を通しで使えるようにしておこう。
</Hook>

<Prediction
  question="$\left(\sqrt{2}x+3\right)\left(\sqrt{2}x-3\right)$ を展開すると、どれになるでしょう？"
  options={['$2x^2-9$', '$2x^2+9$', '$2x^2-6x-9$']}
  answer="$2x^2-9$"
  explanation="$(A+B)(A-B)=A^2-B^2$ の形です。$A=\sqrt2 x$ なので $A^2=(\sqrt2)^2x^2=2x^2$、$B^2=9$。よって $2x^2-9$。根号と展開の型を組み合わせます。"
/>

<Note type="info">
**高校・入試での用途**：入試の最初の小問（計算）は、この4つの型のどれかを素早く判断して処理する力が点差になる。ここが速いほど、後の応用問題に使える時間が増える。
</Note>

この単元で身につける型を、一覧にまとめる。問題を見たときに、まず「どの型か」を決めるのが出発点である。

| 見た目 | 型・公式 | ひとこと |
|---|---|---|
| かっこの前がマイナス | $a-(b-c)=a-b+c$ | かっこ内の全項の符号を変える |
| 同じ文字のかけ算 | $x^m\times x^n=x^{m+n}$ | 指数は足す |
| 累乗の累乗 | $(x^m)^n=x^{mn}$ | 指数は掛ける |
| かっこの外に累乗 | $(2x)^3=8x^3$ | 係数にも指数を配る |
| $(x+a)(x+b)$ | $x^2+(a+b)x+ab$ | 和と積を入れる |
| $(x+a)^2$ | $x^2+2ax+a^2$ | 真ん中を忘れない |
| $(A+B)(A-B)$ | $A^2-B^2$ | 真ん中の項が消える |
| 分母に根号 | 有理化 | 根号を消す |

<Why>
$(A+B)(A-B)$ を「2乗の差」と見抜くのは、この形だけが4項ではなく2項で済む型だからだ。分配法則で全部書くと $A^2-AB+AB-B^2$ となり、真ん中の2項が打ち消し合う。最初から消えると分かっていれば、書く量が半分になり、符号ミスの入る隙も減る。型を覚える目的は、暗記そのものではなく、考える手間と書く手間を同時に削ることにある。
</Why>

<WorkedExample title="総合例題（入試の小問風）">
$x=\sqrt3-1$ のとき、$x^2+2x-1$ の値を求めよ。

<Steps>
<Step reason="そのまま代入すると根号の2乗が出て面倒になる。まず式の形に注目し、$x^2+2x$ の部分をかっこの2乗にまとめる。">$x^2+2x-1=(x+1)^2-2$。</Step>
<Step reason="$x+1$ が簡単な値になる。$x=\sqrt3-1$ なので $x+1=\sqrt3$。">$(x+1)^2-2=(\sqrt3)^2-2$。</Step>
<Step reason="根号の2乗を外して計算する。">$3-2=1$。</Step>
</Steps>

<Answer>
$1$
</Answer>
</WorkedExample>

<Note type="tip">
**検算**：直接代入して確かめられる。$(\sqrt3-1)^2+2(\sqrt3-1)-1=(3-2\sqrt3+1)+2\sqrt3-2-1=1$ となり、同じ答えになる。根号の項が打ち消し合うのが見どころで、この確認で符号ミスを見つけられる。
</Note>

<WorkedExample title="もう1つ: 有理化と根号の整理をつなぐ">
$\dfrac{1}{\sqrt2-1}-\sqrt8$ を計算せよ。

<Steps>
<Step reason="分母に根号があるので、まず有理化する。共役な $\sqrt2+1$ を分母と分子に掛ける。">$\dfrac{\sqrt2+1}{(\sqrt2)^2-1^2}=\dfrac{\sqrt2+1}{2-1}=\sqrt2+1$。</Step>
<Step reason="$\sqrt8$ は $2\sqrt2$ に直しておく。">$\sqrt2+1-2\sqrt2$。</Step>
<Step reason="根号の中が同じ項をまとめる。">$1-\sqrt2$。</Step>
</Steps>

<Answer>
$1-\sqrt2$
</Answer>
</WorkedExample>

<Misconception>
<Wrong>
総合問題は、覚えている公式を1つ当てはめれば解ける。
</Wrong>
<WhyWrong>
入試の小問は、公式を1つ選ぶのではなく、変形の順番を選ぶ問題である。$x=\sqrt3-1$ で $x^2+2x-1$ を求めるときは、代入の前に $(x+1)^2-2$ と見る判断が必要で、その判断は「根号の計算を減らす」という目的から来ている。公式の当てはめだけでは、その一手が出てこない。
</WhyWrong>
<Right>
まず求める式を簡単な形に直し、その後で値を入れる。検算として別の順序でもう一度確かめる。手順を選ぶ力が、計算の速さと正確さを同時に上げる。
</Right>
</Misconception>

<Misconception>
<Wrong>
$\dfrac{\sqrt2-1}{2}$ は分母を有理化していないので、間違いである。
</Wrong>
<WhyWrong>
有理化が必要なのは、分母に根号が残っているときだけである。分母が $2$ のような整数なら、そのままでも何の問題もない。形だけで何でも有理化すると、かえって計算が増えてミスの余地が広がる。
</WhyWrong>
<Right>
分母に根号があるときだけ有理化する。$\dfrac{1}{\sqrt2}$ は $\dfrac{\sqrt2}{2}$ に直し、$\dfrac{\sqrt2}{2}$ はそのままでよい。
</Right>
</Misconception>

<CheckUnderstanding>
（1）$(-3x)^2\times2x$ を計算せよ。
<Reveal label="答え">
かっこの外の2乗を係数と文字の両方に配る。$(-3x)^2=9x^2$。これに $2x$ を掛けて $18x^3$。
</Reveal>

（2）$(x-\sqrt5)(x+\sqrt5)$ を展開せよ。
<Reveal label="答え">
2乗の差の公式より $x^2-(\sqrt5)^2=x^2-5$。
</Reveal>

（3）$x=\sqrt5-2$ のとき、$x^2+4x+4$ の値を求めよ。
<Reveal label="答え">
$x^2+4x+4=(x+2)^2$。$x+2=\sqrt5$ なので $(\sqrt5)^2=5$。
</Reveal>

（4）$\dfrac{1}{\sqrt5-2}$ を有理化せよ。
<Reveal label="答え">
共役な $\sqrt5+2$ を分母と分子に掛ける。$\dfrac{\sqrt5+2}{5-4}=\sqrt5+2$。
</Reveal>
</CheckUnderstanding>

<Practice title="練習（単元の総仕上げ）">
（1）$(-2ab)^2\div4a\times b$ を計算せよ。

（2）$2(\sqrt3-\sqrt2)-3(\sqrt2-\sqrt3)$ を計算せよ。

（3）$x=\sqrt2+1$ のとき、$x^2-2x+3$ の値を求めよ。

（4）$\dfrac{1}{\sqrt3-2}$ を有理化せよ。

<Reveal label="解答">
（1）$(-2ab)^2=4a^2b^2$。$4a^2b^2\div4a=ab^2$。これに $b$ を掛けて $ab^3$。

（2）かっこを外す。$2\sqrt3-2\sqrt2-3\sqrt2+3\sqrt3$。$\sqrt3$ の項と $\sqrt2$ の項をまとめて $5\sqrt3-5\sqrt2$。

（3）$x^2-2x+3=(x-1)^2+2$ と変形する。$x-1=\sqrt2$ なので $(\sqrt2)^2+2=2+2=4$。

（4）共役な $\sqrt3+2$ を掛ける。分母は $(\sqrt3)^2-2^2=3-4=-1$。よって $\dfrac{\sqrt3+2}{-1}=-\sqrt3-2$。2乗して確かめると $(-\sqrt3-2)^2=3+4\sqrt3+4=7+4\sqrt3$ で、$1/(\sqrt3-2)=1/(-0.268)\approx-3.73$、$-\sqrt3-2\approx-3.73$ と一致する。
</Reveal>
</Practice>
