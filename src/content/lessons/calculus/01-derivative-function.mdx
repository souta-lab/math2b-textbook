<Hook>
前のレッスンでは、曲線上の1つの点を選んで、その点の接線の傾きを定義どおりに計算しました。しかし曲線には点が無数にあります。接線の傾きを知りたい点が変わるたびに、同じ計算をやり直すのは非効率です。傾きのほうも、$x$ の関数としてまとめて表せないでしょうか。
</Hook>

前のレッスンで得た $f(x)=x^2$ の結果を思い出しましょう。$x=a$ における微分係数は $f'(a)=2a$ でした。この $a$ はどの値でもよかったので、$a$ を文字 $x$ に置き換えれば、各点の傾きをまとめて $2x$ と書けます。たとえば $x=3$ なら $6$、$x=-1$ なら $-2$ です。

<Figure caption="y = x³ 上の点を動かすと、接線の傾きが 3a² にしたがって変わるようす。">
<TangentSlope fn="cubic" a={1} h={1} interactive />
</Figure>

上の図で点を動かすと、同じ曲線でも場所によって接線の傾きが変わり、$x$ が負のところでは傾きも負になることが見えます。このように、各点の微分係数を $x$ の関数としてまとめたものが導関数です。

<Why>
各点で定義どおりに極限を計算していたのでは、点の数だけ手間がかかります。そこで、$x$ を文字のまま計算してしまうのです。$x$ のまま展開・約分しておけば、得られた式に好きな値を代入するだけで、どの点の傾きも一度に分かります。公式として覚える前に、一度は文字のまま計算して納得しておきましょう。
</Why>

<Definition term="導関数">
関数 $f(x)$ の各 $x$ に対して、その点の微分係数 $f'(x)$ を対応させた関数を、$f(x)$ の**導関数**という。導関数を求めることを、$f(x)$ を**微分する**という。導関数は

$$
\frac{f(x+h)-f(x)}{h}
$$

で $h$ を $0$ に近づけたときの値として定められる。
</Definition>

前のレッスンと同じ手順を、$x$ を残したまま行えば導関数が得られます。$f(x)=x^3$ で確かめてみましょう。

$$
\frac{(x+h)^3-x^3}{h}
=\frac{x^3+3x^2h+3xh^2+h^3-x^3}{h}
=\frac{3x^2h+3xh^2+h^3}{h}
=3x^2+3xh+h^2.
$$

$h$ を $0$ に近づけると、$3xh$ と $h^2$ が消えて $3x^2$ が残ります。同じ計算を $x^2$、$x^3$、$x^4$ と繰り返すと、次の公式にまとまります。

<Theorem name="導関数の公式">
$n$ を正の整数、$c$、$k$ を定数とするとき

$$
(x^n)' = n\,x^{n-1},\qquad (c)' = 0,
$$

$$
\{k\,f(x)\}' = k\,f'(x),\qquad \{f(x)+g(x)\}' = f'(x)+g'(x).
$$
</Theorem>

1つ目の式 $(x^n)'=n x^{n-1}$ は、展開の公式から $h$ の1次の項の係数だけが生き残ることを表しています。2つ目の $(c)'=0$ は、$y=c$ のグラフが水平な直線で、接線の傾きがどこでも $0$ だからです。3つ目と4つ目は、微分が項ごとに計算できることを述べています。

<WorkedExample title="例題: 導関数を求める">
$y=x^3-4x+2$ を微分しなさい。

<Steps>
<Step reason="和の導関数は、項ごとの導関数の和に分けられるからです。">$y'=(x^3)'-(4x)'+(2)'$。</Step>
<Step reason="公式 (xⁿ)′ = n xⁿ⁻¹ を n = 3 に使うと、3·x² が出ます。">$(x^3)'=3x^2$。</Step>
<Step reason="定数倍はそのまま前に出し、(x)′ = 1 だからです。">$(4x)'=4\cdot 1=4$。</Step>
<Step reason="定数のグラフは水平で、どの点でも接線の傾きが 0 だからです。">$(2)'=0$。</Step>
</Steps>

<Answer>
$y'=3x^2-4$。
</Answer>
</WorkedExample>

<WorkedExample title="例題: 3次関数の導関数と接線の傾き">
$y=2x^3-6x^2+5$ について、導関数 $y'$ を求めなさい。また、$x=1$ における接線の傾きを求めなさい。

<Steps>
<Step reason="和の導関数は項ごとの導関数の和に分けられるからです。">$y'=(2x^3)'-(6x^2)'+(5)'$。</Step>
<Step reason="定数倍は前に出し、公式 (xⁿ)′ = n xⁿ⁻¹ を n = 3 に使うと 2·3x² = 6x² が出ます。">$(2x^3)'=2\cdot 3x^2=6x^2$。</Step>
<Step reason="同じ公式を n = 2 に使うと 6·2x = 12x が出ます。">$(6x^2)'=6\cdot 2x=12x$。</Step>
<Step reason="定数のグラフは水平で、どの点でも接線の傾きが 0 だからです。">$(5)'=0$ なので $y'=6x^2-12x$。</Step>
<Step reason="導関数は各点の接線の傾きをまとめた関数なので、x = 1 を代入すればその点の傾きが得られるからです。">$x=1$ を代入すると $y'=6-12=-6$。接線は右下がりで、傾きは $-6$。</Step>
</Steps>

<Answer>
導関数は $y'=6x^2-12x$。$x=1$ における接線の傾きは $-6$。
</Answer>
</WorkedExample>

<Why>
多項式を微分するとき、なぜ各項をばらばらに微分してよいのでしょうか。微分係数は「差をとって幅で割る」という計算で作られており、この計算は和と定数倍の構造をそのまま保ちます。実際、$\{f(x)+g(x)\}'$ は $f$ と $g$ の変化の割合を別々に求めて足したものに一致し、$\{k f(x)\}'$ は変化の割合を $k$ 倍したものに一致します。だから $2x^3-6x^2+5$ のような多項式でも、次数の違う項をまとめて工夫する必要はなく、$(x^n)'=nx^{n-1}$ を項ごとに当てはめるだけで導関数が組み立てられるのです。
</Why>

<Misconception>
<Wrong>
$y=5$ のような定数を微分すると、$y'=5$ である。
</Wrong>
<WhyWrong>
導関数が表すのはグラフの傾きです。$y=5$ のグラフは $x$ 軸に平行な水平な直線で、どの点でも接線の傾きは $0$ です。微分すると、$x$ を含まない定数の情報は消えます。
</WhyWrong>
<Right>
定数の導関数は $0$、すなわち $(c)'=0$。定数を微分しても、その定数自身は残りません。
</Right>
</Misconception>

<CheckUnderstanding>
（1）導関数と微分係数の関係を、自分の言葉で説明しなさい。
<Reveal label="答え">
導関数は、各 $x$ における微分係数を値とする関数。微分係数 $f'(a)$ は導関数 $f'(x)$ に $x=a$ を代入したもの。
</Reveal>

（2）$y=x^4$ を微分しなさい。
<Reveal label="答え">
$y'=4x^3$。
</Reveal>

（3）$y=3x^2-2x+5$ を微分しなさい。
<Reveal label="答え">
$y'=6x-2$。
</Reveal>
</CheckUnderstanding>

<Practice title="まとめの練習（微分係数と導関数）">
（1）$f(x)=x^3-2x$ の導関数 $f'(x)$ を求め、$x=-1$ における微分係数 $f'(-1)$ を計算せよ。
（2）$f(x)=2x^3-3x^2+1$ について、区間 $[0,\ 2]$ の平均変化率を求めよ。また導関数 $f'(x)$ を求め、$x=2$ における微分係数と比べよ。
（3）$f(x)=x^3+ax^2-3x+2$ の導関数が $f'(1)=0$ をみたすとき、定数 $a$ の値を求めよ。また、そのとき $f'(x)=0$ を解け。
<Reveal label="解答">
（1）$(x^n)'=nx^{n-1}$、定数倍の微分、和の微分を使うと $f'(x)=3x^2-2$。よって $f'(-1)=3\cdot(-1)^2-2=1$。
（2）平均変化率は $\dfrac{f(2)-f(0)}{2-0}=\dfrac{(16-12+1)-1}{2}=\dfrac{4}{2}=2$。導関数は $f'(x)=6x^2-6x$ なので、$x=2$ における微分係数は $f'(2)=24-12=12$。$x=2$ での瞬間の傾きは、区間全体の平均変化率より大きい。
（3）$f'(x)=3x^2+2ax-3$。$f'(1)=3+2a-3=2a$ なので、$2a=0$ より $a=0$。このとき $f'(x)=3x^2-3=3(x-1)(x+1)$ だから、$f'(x)=0$ の解は $x=\pm 1$。
</Reveal>
</Practice>
