## 6つの道具を「いつ使うか」で整理する

章末の融合問題で最初にすべきことは、式の計算ではなく、問いの種類の見きわめです。次の表は、この単元で学んだ道具を「何を知りたいか」から引けるように整理したものです。

| 知りたいこと | 使う道具 | 判断の決め手 |
| --- | --- | --- |
| 値ごとの起こりやすさを並べる | 確率分布（離散型） | とりうる値と確率の対応表を作る。確率の和は必ず $1$ |
| 分布の中心と散らばりを1つの数にする | 期待値・分散・標準偏差 | 値×確率の和が期待値。$V[X]=E[X^2]-(E[X])^2$ |
| 同じ試行を $n$ 回繰り返した成功回数 | 二項分布 $B(n,p)$ | 独立で確率が一定。$E[X]=np$、$V[X]=np(1-p)$ |
| 連続量が平均のまわりに集まるようす | 正規分布と標準化 | $Z=(X-\mu)/\sigma$。$N(\mu,\sigma^2)$ の第2の数は分散 |
| 母平均・母比率のありかを幅で言う | 区間推定 | 標準誤差に境界値を掛ける（95%なら $1.96$） |
| 「差がある・偏りがある」と言えるか決める | 仮説検定 | 帰無仮説のもとで $z$ を計算し、両側5%なら $z$ の絶対値が $1.96$ 以上 |

表の見方を2つの例で確かめます。「400人のうち賛成は何人か」という問いなら、成功回数の話なので3行目の二項分布。「賛成率はどのあたりか」なら5行目の区間推定、「賛成率は0.5と言えるか」なら6行目の仮説検定です。同じデータでも、問いが変われば見る行が変わります。

<KeyPoint>
道具選びの軸は、式の形ではなく問いの形です。値を並べるなら確率分布、中心と散らばりなら期待値・分散、成功回数なら二項分布、連続量なら正規分布と標準化、母数を幅で言うなら区間推定、差の有無を決めるなら仮説検定。問題文にキーワードがなくても、データが生まれた仕組みから選びます。
</KeyPoint>

<Why>
6つの道具を別々に覚えると、章末の融合問題で「最初の一手」が選べなくなります。しかし、この章の計算はすべて「ずれを、散らばりのものさしで測る」という1つの操作に還元できます。区間推定では標準誤差をものさしにして標本平均のずれを測り、仮説検定では帰無仮説のもとでの標準偏差をものさしにして観測値のずれを測ります。同じ標準化の操作を使うからこそ、95%信頼区間と有意水準5%の検定はどちらも $1.96$ という同じ境界を共有します。数学Iの「データの分析」で平均と標準偏差を学んだときから、中心からのずれを測るという見方は変わっていません。
</Why>

## 発展問題 — 推定と検定を1つのデータでつなぐ

表の3行目・5行目・6行目を、1つのデータでつないでみましょう。400人の賛否という同じ観測結果を、まず幅でとらえ、次に「0.5と違うか」という判断に使います。

<WorkedExample title="発展（入試風）: 二項分布を正規近似し、推定と検定で同じ境界を使う">
ある市の有権者から無作為に400人を選び、政策Aへの賛否を聞いたところ、賛成は240人だった。市全体の賛成率を $p$ とし、各人は独立に確率 $p$ で賛成するとみなす。

（1）賛成者数 $X$ の期待値と標準偏差を、$p$ を用いて表せ。
（2）標本比率 $\hat{p}$ を求め、$p$ の95%信頼区間を求めよ。
（3）「$p=0.5$ である」という主張を、有意水準5%の両側検定で検定せよ。
（4）（2）と（3）の結論が一致したのはなぜか。$1.96$ という値に触れて説明せよ。

<Steps>
<Step reason="400人それぞれの賛否は独立で、賛成する確率はどれも同じ p とみなせるので、成功回数の分布が使えます。">$X$ は二項分布 $B(400, p)$ に従う。</Step>
<Step reason="二項分布の期待値と標準偏差の公式に、試行回数 400 を代入します。">$E[X] = 400p$、$\sigma = \sqrt{400p(1-p)} = 20\sqrt{p(1-p)}$。</Step>
<Step reason="まず観測された標本比率を、賛成者数を標本の大きさで割って求めます。">$\hat{p} = \frac{240}{400} = 0.6$。</Step>
<Step reason="母比率の標準誤差は、未知の p を観測された標本比率で置き換えて見積もります。">標準誤差は $\sqrt{\frac{\hat{p}(1-\hat{p})}{400}} = \sqrt{\frac{0.6 \times 0.4}{400}} = \sqrt{0.0006} \approx 0.0245$。</Step>
<Step reason="95%に対応する境界値1.96に標準誤差を掛けると、区間の幅の半分が求まります。">マージンは $1.96 \times 0.0245 \approx 0.048$。よって $0.6 - 0.048 \le p \le 0.6 + 0.048$、すなわち $0.552 \le p \le 0.648$。</Step>
<Step reason="検定は「差がない」という仮説をいったん置き、そのもとで結果の珍しさを測るのでした。">帰無仮説 $H_0: p = 0.5$、対立仮説 $H_1: p \ne 0.5$ とする。</Step>
<Step reason="H0 のもとでは p=0.5 を使えるので、期待値と標準偏差を二項分布の公式どおりに計算します。">$E[X] = 400 \times 0.5 = 200$、$\sigma = \sqrt{400 \times 0.5 \times 0.5} = 10$。割合の標準誤差で見ると $\sqrt{0.5 \times 0.5 / 400} = 0.025$。</Step>
<Step reason="観測値が期待値から標準偏差いくつ分離れているかを、標準化して測ります。">$z = \frac{240 - 200}{10} = 4$。割合で計算しても $z = \frac{0.6 - 0.5}{0.025} = 4$。</Step>
<Step reason="両側5%の棄却域の境界1.96と比べて、棄却するかどうかを決めます。">$|z| = 4 > 1.96$ なので、$H_0$ は棄却される。賛成率は $0.5$ とは異なると判断できる。</Step>
<Step reason="推定と検定が、同じ標準正規分布の境界を基準にしていることを確かめます。">95%信頼区間は $0.5$ を含まず、検定統計量は棄却域に入った。どちらも標準正規分布の両側5%の境界 $1.96$ を物差しにしているため、結論が一致する。</Step>
</Steps>

<Answer>
（1）$E[X] = 400p$、$\sigma = 20\sqrt{p(1-p)}$。
（2）$\hat{p} = 0.6$、$0.552 \le p \le 0.648$。
（3）$z = 4$ で $|z| > 1.96$ だから $H_0$ を棄却。賛成率は $0.5$ とは異なると判断できる。
（4）どちらも標準正規分布の両側5%の境界 $1.96$ を基準にしており、$0.5$ は信頼区間の外、$z=4$ は棄却域の中にある。
</Answer>
</WorkedExample>

（3）の計算を1本にまとめると、次のようになります。この値が境界を超えるかどうかが、検定の結論を決めました。

$$
z = \frac{240 - 200}{10} = 4, \qquad |z| = 4 > 1.96
$$

<Note type="info">
信頼区間では未知の $p$ を $\hat{p}$ で置き換えた標準誤差 $\sqrt{\hat{p}(1-\hat{p})/n}$ を使いますが、検定では帰無仮説の値 $p_0$ を使った $\sqrt{p_0(1-p_0)/n}$ を使います。今回は $0.0245$ と $0.025$ でほぼ同じでしたが、何を既知とみなすかが違うため、境目ぎりぎりのときは2つの判断が分かれることもあります。
</Note>

<SelfExplanation
  prompt="賛成率の差 0.1 を評価するとき、そのままの差ではなく標準偏差で割って z に直すのはなぜ？"
  options={['差の珍しさは、散らばりの大きさと比べて初めて測れるから', '差を必ず整数に直すため', '標準偏差を小さくするため']}
  model="標本比率は試行のたびに変動するので、差の大小は散らばりの大きさとの比で判断します。標準偏差で割って z に直すと、どんな問題でも標準正規分布の同じ境界（両側5%なら1.96）と比べられるようになります。"
/>

<Misconception>
<Wrong>
賛成率は60%で、主張の50%との差は10ポイントしかない。標本の偶然のばらつきでこれくらいずれるのは普通なので、$p=0.5$ を棄却するのは無理がある。
</Wrong>
<WhyWrong>
差の大きさは、散らばりのものさしと比べて初めて意味をもちます。$p=0.5$ と仮定すると、400人の賛成者数の標準偏差は $\sqrt{400 \times 0.5 \times 0.5} = 10$ 人で、240人は期待値200から4標準偏差分。標準化すると $z=4$ となり、両側5%の境界1.96を大きく超えます。割合で見ても、標準誤差は $\sqrt{0.5 \times 0.5/400} = 0.025$ で、差 $0.1$ はその4倍です。見た目の10ポイントだけでは珍しさは測れません。
</WhyWrong>
<Right>
珍しさは、期待値からの差を標準偏差で割った値（$z$）で測り、あらかじめ決めた境界と比べます。両側5%なら境界は $1.96$ です。標準偏差には試行回数 $n$ が入っているので、同じ差でも $n$ が大きいほど珍しくなります。
</Right>
</Misconception>

## 単元をまたぐ確認問題

次の3問は、この単元の別々のレッスンから選んだものです。どの道具を使うかを判断してから解いてください。

<CheckUnderstanding>
（1）袋の中に赤玉が3個、白玉が2個入っている。この袋から同時に2個の玉を取り出し、赤玉の個数を $X$ とする。$X$ の確率分布を求め、$E[X]$ と $V[X]$ を計算せよ。

（2）さいころを600回投げるとき、1の目が出る回数を $X$ とする。$E[X]$ と $\sigma$ を求め、$P(85 \le X \le 115)$ を二項分布の正規近似で求めよ。ただし $\Phi(1.64) = 0.9495$ とする。

（3）ある試験の得点 $X$ は正規分布 $N(64, 100)$ に従う。$P(54 \le X \le 74)$ を68–95–99.7の目安で求め、$P(X \ge 84)$ を $\Phi(2) = 0.9772$ を用いて求めよ。
<Reveal label="答え">
（1）取り出し方は ${}_5\mathrm{C}_2 = 10$ 通り。$P(X=0) = \frac{1}{10}$、$P(X=1) = \frac{3 \times 2}{10} = \frac{3}{5}$、$P(X=2) = \frac{3}{10}$ で、和は $1$。$E[X] = 0 \times \frac{1}{10} + 1 \times \frac{6}{10} + 2 \times \frac{3}{10} = \frac{6}{5}$。$E[X^2] = 1 \times \frac{6}{10} + 4 \times \frac{3}{10} = \frac{9}{5}$ なので、$V[X] = \frac{9}{5} - \left(\frac{6}{5}\right)^2 = \frac{9}{25}$。

（2）$E[X] = 600 \times \frac{1}{6} = 100$、$V[X] = 600 \times \frac{1}{6} \times \frac{5}{6} = \frac{250}{3}$ より $\sigma = \sqrt{\frac{250}{3}} \approx 9.13$。標準化すると $85$ は $z = \frac{85-100}{9.13} \approx -1.64$、$115$ は $z \approx 1.64$。よって $P(85 \le X \le 115) \approx 2 \times 0.9495 - 1 = 0.899$。

（3）$N(64, 100)$ の第2の数は分散なので $\sigma = \sqrt{100} = 10$。$54$ は $z = -1$、$74$ は $z = 1$ なので $P(54 \le X \le 74) \approx 0.683$。$84$ は $z = 2$ なので $P(X \ge 84) = 1 - 0.9772 = 0.0228$。
</Reveal>
</CheckUnderstanding>

## 章末演習 — 同じデータで推定と検定

<Practice title="章末演習（同じデータで推定と検定）">
ある果樹園で採れる果実1個の重さは、母標準偏差 $\sigma = 20$ g の正規分布に従う。無作為に $25$ 個を選んだところ、標本平均は $\bar{x} = 180$ g であった。

（1）母平均 $\mu$ の95%信頼区間を求めよ。
（2）「$\mu = 170$ g である」という主張を、有意水準5%の両側検定で検定せよ。
（3）（1）と（2）の判断が一致する理由を、境界値 $1.96$ に触れて説明せよ。
<Reveal label="解答">
（1）標準誤差は $\frac{20}{\sqrt{25}} = 4$。95%のマージンは $1.96 \times 4 = 7.84$ なので、$180 - 7.84 \le \mu \le 180 + 7.84$、すなわち $172.16 \le \mu \le 187.84$。

（2）帰無仮説は $H_0: \mu = 170$。標本平均の標準誤差は $4$ なので、$z = \frac{180 - 170}{4} = 2.5$。$|z| = 2.5 > 1.96$ より $H_0$ を棄却する。果実の平均の重さは $170$ g とは異なると判断できる。

（3）95%信頼区間は、両側5%の検定で棄却されない仮の平均 $\mu_0$ を全部集めた区間になっている。実際、$170$ は信頼区間 $172.16 \le \mu \le 187.84$ の外にあり、検定でも $z = 2.5$ が棄却域 $|z| \ge 1.96$ に入る。どちらも標準正規分布の中央95%と両端5%という同じ境界 $1.96$ を基準にしているため、判断が一致する。
</Reveal>
</Practice>
