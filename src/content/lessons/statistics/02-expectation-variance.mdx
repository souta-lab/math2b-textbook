## 確率で重み付けしてならす

前のレッスンで、確率変数 $X$ がどんな値をどの確率でとるか、確率分布の表を作りました。ここではその表から、$X$ の「中心」と「散らばり」を1つの数で取り出します。中心は、値を確率で重み付けしてならした平均です。起こりやすい値ほど強く効かせたいので、値にその確率を掛けて足します。

<Why>
たとえばさいころの目を普通に足して6で割れば、どの目も同様に確からしいので同じ結果になりますが、当たり外れのある宝くじでは各金額の起こりやすさが違います。値そのものの平均ではなく「値 × 確率」の和にすることで、起こりやすい結果を重く、めったに起きない結果を軽く数えられます。データの平均が各値を同じ重みで足したのに対し、期待値は確率という重みで足している点が対応しています。
</Why>

<Definition term="期待値・分散・標準偏差">
離散型の確率変数 $X$ が $x_1, x_2, \dots, x_n$ を確率 $p_1, p_2, \dots, p_n$ でとるとする。$X$ の**期待値**（平均）$\mu = E[X]$ を
$$
E[X] = x_1p_1 + x_2p_2 + \dots + x_np_n = \sum_{i=1}^{n} x_i p_i
$$
と定める。また、$(X-\mu)^2$ の期待値を**分散** $V[X] = \sigma^2$ といい、
$$
V[X] = E[(X-\mu)^2] = \sum_{i=1}^{n} (x_i-\mu)^2 p_i
$$
で定める。その正の平方根 $\sigma = \sqrt{V[X]}$ を**標準偏差**という。
</Definition>

期待値は確率で重み付けした平均、分散は「平均との差の2乗」を確率で重み付けした平均です。前のレッスンのデータの分散と形は同じで、各値を1回ずつ数える代わりに、確率という重みを掛けているだけです。

計算を少し楽にする公式を用意します。分散は「2乗の期待値」から「期待値の2乗」を引いても求められます。

<Theorem name="期待値・分散の公式">
確率変数 $X$ と定数 $a$、$b$ について、次が成り立つ。
$$
E[aX+b] = aE[X] + b, \qquad V[aX+b] = a^2\,V[X], \qquad \sigma[aX+b] = |a|\,\sigma[X]
$$
また、$\mu = E[X]$ とすると
$$
V[X] = E[X^2] - \mu^2
$$
である。
</Theorem>

<WorkedExample title="例題1: 2枚の硬貨の期待値・分散・標準偏差">
2枚の硬貨を投げて表の枚数を $X$ とする。$X$ の確率分布は $P(X=0)=\dfrac{1}{4}$、$P(X=1)=\dfrac{1}{2}$、$P(X=2)=\dfrac{1}{4}$ である。$E[X]$、$V[X]$、$\sigma$ を求めよ。

<Steps>
<Step reason="期待値は値と確率を掛けて全部足します。">$E[X] = 0\cdot\dfrac{1}{4} + 1\cdot\dfrac{1}{2} + 2\cdot\dfrac{1}{4} = 1$。</Step>
<Step reason="分散の公式 V[X]=E[X²]−μ² を使うために、まず X² の期待値を出します。">$E[X^2] = 0^2\cdot\dfrac{1}{4} + 1^2\cdot\dfrac{1}{2} + 2^2\cdot\dfrac{1}{4} = \dfrac{1}{2} + 1 = \dfrac{3}{2}$。</Step>
<Step reason="2乗の期待値から期待値の2乗を引けば分散になります。">$V[X] = \dfrac{3}{2} - 1^2 = \dfrac{1}{2}$。</Step>
<Step reason="標準偏差は分散の平方根で、X と同じ単位になります。">$\sigma = \sqrt{\dfrac{1}{2}} = \dfrac{\sqrt{2}}{2} \approx 0.71$。</Step>
</Steps>

<Answer>
$E[X] = 1$、$V[X] = \dfrac{1}{2}$、$\sigma \approx 0.71$。
</Answer>
</WorkedExample>

<WorkedExample title="例題2: 一次変換した確率変数">
例題1の $X$ に対し、$Y = 10X + 5$ とおく。$E[Y]$、$V[Y]$、$Y$ の標準偏差を求めよ。

<Steps>
<Step reason="期待値の一次変換は、そのまま係数を外に出せます。">$E[Y] = 10E[X] + 5 = 10\cdot1 + 5 = 15$。</Step>
<Step reason="分散は係数が2乗されて外に出るので、足す5は散らばりに影響しません。">$V[Y] = 10^2\,V[X] = 100\cdot\dfrac{1}{2} = 50$。</Step>
<Step reason="標準偏差は分散の平方根で、係数の絶対値がそのまま外に出ます。">$Y$ の標準偏差は $\sqrt{50} = 5\sqrt{2} \approx 7.07$。</Step>
</Steps>

<Answer>
$E[Y] = 15$、$V[Y] = 50$、$Y$ の標準偏差は $5\sqrt{2} \approx 7.07$。
</Answer>
</WorkedExample>

<SelfExplanation
  prompt="2枚の硬貨の例で、分散を V[X]=E[X²]−μ² で求められるのはなぜ？"
  options={['E[(X−μ)²] を展開すると E[X²]−2μE[X]+μ² となり、E[X]=μ だから', 'X² の期待値がいつも μ² に等しいから', '標準偏差を2乗すると分散になるから']}
  model="E[(X−μ)²] を展開すると E[X²]−2μE[X]+μ² です。E[X]=μ を代入すると E[X²]−2μ²+μ²=E[X²]−μ² となり、2乗の期待値と期待値の2乗だけで分散が求まります。"
/>

<Misconception>
<Wrong>
$E[X^2]$ と $(E[X])^2$ はいつでも等しい。
</Wrong>
<WhyWrong>
2枚の硬貨の例では $E[X^2]=\dfrac{3}{2}$ ですが、$(E[X])^2=1^2=1$ で等しくありません。期待値は「各値を1回ずつ」ならすのに対し、$X^2$ の期待値は大きい値を2乗してからならすので、一般に大きい側へ引っ張られます。等号が成り立つのは $X$ が定数のときだけです。
</WhyWrong>
<Right>
$E[X^2]$ と $(E[X])^2$ は別の量です。その差が分散 $V[X]=E[X^2]-(E[X])^2$ で、いつも $0$ 以上になります。
</Right>
</Misconception>

<Misconception>
<Wrong>
期待値は、確率変数が実際にとる値のどれか1つに必ず一致する。
</Wrong>
<WhyWrong>
さいころの目の期待値は $3.5$ ですが、さいころの目に $3.5$ はありません。期待値は「同じ試行を多数回繰り返したときの1回あたりの平均が近づいていく値」であって、1回の結果そのものではありません。
</WhyWrong>
<Right>
期待値は分布の中心を表す計算上の値で、実際の値と一致するとは限りません。繰り返し回数を増やすほど、結果の平均が期待値に近づいていきます。
</Right>
</Misconception>

<CheckUnderstanding>
(1) 確率変数 $X$ が $1$ を確率 $\dfrac{1}{3}$、$4$ を確率 $\dfrac{1}{2}$、$9$ を確率 $\dfrac{1}{6}$ でとるとき、$E[X]$ を求めよ。

(2) この $X$ について $E[X^2]$ を求め、$V[X]$ を計算せよ。

(3) $Y = 2X - 1$ のとき、$E[Y]$ と $V[Y]$ を求めよ。
<Reveal label="答え">
(1) $E[X] = 1\cdot\dfrac{1}{3} + 4\cdot\dfrac{1}{2} + 9\cdot\dfrac{1}{6} = \dfrac{2}{6} + \dfrac{12}{6} + \dfrac{9}{6} = \dfrac{23}{6} \approx 3.83$。

(2) $E[X^2] = 1\cdot\dfrac{1}{3} + 16\cdot\dfrac{1}{2} + 81\cdot\dfrac{1}{6} = \dfrac{2}{6} + \dfrac{48}{6} + \dfrac{81}{6} = \dfrac{131}{6}$。よって $V[X] = \dfrac{131}{6} - \left(\dfrac{23}{6}\right)^2 = \dfrac{786 - 529}{36} = \dfrac{257}{36} \approx 7.14$。

(3) $E[Y] = 2\cdot\dfrac{23}{6} - 1 = \dfrac{23}{3} - 1 = \dfrac{20}{3} \approx 6.67$。$V[Y] = 2^2 V[X] = 4\cdot\dfrac{257}{36} = \dfrac{257}{9} \approx 28.6$。
</Reveal>
</CheckUnderstanding>

<Practice title="まとめの練習（散らばりと一次変換）">
確率変数 $X$ は $1$、$2$、$3$ をそれぞれ $\dfrac{1}{6}$、$\dfrac{1}{3}$、$\dfrac{1}{2}$ の確率でとる。
（1）$E[X]$、$E[X^2]$、$V[X]$、$\sigma$ を求めよ。
（2）$Y=X+10$、$Z=3X-2$ について、それぞれの期待値と分散を求めよ。また $V[Y]=V[X]$ となる理由を、データの平行移動と関連づけて説明せよ。
（3）$E[X]=2$、$V[X]=3$ である別の確率変数 $W$ を $W=-2X+5$ で定めるとき、$E[W]$、$V[W]$、$W$ の標準偏差を求めよ。
<Reveal label="解答">
（1）$E[X]=1\cdot\dfrac{1}{6}+2\cdot\dfrac{1}{3}+3\cdot\dfrac{1}{2}=\dfrac{1+4+9}{6}=\dfrac{14}{6}=\dfrac{7}{3}$。$E[X^2]=1^2\cdot\dfrac{1}{6}+2^2\cdot\dfrac{1}{3}+3^2\cdot\dfrac{1}{2}=\dfrac{1+8+27}{6}=\dfrac{36}{6}=6$。よって $V[X]=E[X^2]-(E[X])^2=6-\dfrac{49}{9}=\dfrac{5}{9}$、$\sigma=\sqrt{\dfrac{5}{9}}=\dfrac{\sqrt{5}}{3}$。
（2）$E[Y]=E[X]+10=\dfrac{7}{3}+10=\dfrac{37}{3}$、$V[Y]=V[X]=\dfrac{5}{9}$。$E[Z]=3E[X]-2=7-2=5$、$V[Z]=3^2V[X]=9\cdot\dfrac{5}{9}=5$。$Y$ は $X$ に定数 $10$ を足したもので、データの場合と同じく平行移動にあたる。各値は $10$ だけずれるが、平均からの差は変わらないので、散らばりを表す分散も変化しない。
（3）$E[W]=-2E[X]+5=-2\cdot 2+5=1$。$V[W]=(-2)^2V[X]=4\cdot 3=12$。標準偏差は $\sqrt{12}=2\sqrt{3}$。
</Reveal>
</Practice>
